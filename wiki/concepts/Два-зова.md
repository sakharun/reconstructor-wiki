# Два ЗОВа

## Summary
ЗОВ проходит дважды при создании объединения: первый формирует команду исполнителей, второй приводит управленцев/начало. Только после подтверждения спускается задача.

## Current Understanding
- **Первый ЗОВ** собирает команду исполнителей («по перечню становись, стройсь»): слесари, сантехники и т.п.
- **Второй ЗОВ** приводит начальника/управленцев
- Идти за задачей: только если есть подтверждение объединения — спускается задача и запускается исполнение
- Иногда оба ЗОВа собирают всех вместе — тогда выяснение, кто начало, идёт через специфичную (проверочную) ситуацию
- Принцип на бытовом уровне: набиралась команда корабля, потом приглашался капитан (редкая, дорогая фигура); капитан мог отбраковать часть команды и только затем выход в плавание
- Пираты = «второй вариант»: признание капитана через событие-разборки (без предварительного приглашения)
- Связан с [[Событие-вычленения]]: при совместном ЗОВе начало проявляется через событие среди собранных
- «Капитан не ходил и не искал себе команду» — начало приходит к уже готовой команде; исключение — критическая ситуация (см. [[Начальник]])
