# Прославление

## Summary
Качество, использованное странниками второй воли для разъединения нашей цивилизации: сначала по богам (война богов через чувство несправедливости), затем вниз — как избранность (еврейский народ объявлен избранным). В мире известно как фашизм. Противоядие — целостное восприятие и равнозначимость каждого элемента мира.

## Current Understanding
- Прославление = качество, за счёт которого нас **разъединили** («мы же славяне, богов славим»)
- Странники второй воли изучали нас **~2 000 лет**, выясняя слабые места, прежде чем начать
- **Первый удар — по богам:** прославили (выделили) нескольких богов → чувство несправедливости (качество женского начала) → **война богов**; эксперимент с похвалой «любимчиков» в любом коллективе воспроизводит этот процесс
- **Второй удар — вниз:** прославление вниз проявляется как **избранность** («механики — избранные» → тот же конфликт); народ поднялся на тех, кого больше угнетали
- **Прославление = фашизм** в другом названии («еврейский фашизм»); еврейский народ — найденное слабое звено, объявленное избранным
- Гордость — **системное качество**, к прославлению не относится
- **Противоядие:** целостное восприятие мира, внутреннее понимание **равнозначимости каждого элемента** — «без него мир не существует»; тогда манипуляции прославлением разбиваются «как волны об камень»
- Мужское начало ведётся на прославление сильнее («как белка на орех»)
- Стих источника: «И славы вал затмит рассудок, / Ты бессознательный поступок, / Ты управляемый поток»
- **Славить ≠ хвалить/прославлять (семинар 52):** сутьевое прочтение «славить» = С + ЛА (Аал, высшее проявление) + ВИТЬ — работа с событийным полем ([[Сверхсознание]]); славить могут только Боги, но не богов; «прославление богов» людьми = подмена ролей (см. [[Славить]])
- **Прославление в коллективе = пришёл разрушитель (семинар 52):** усиленное внимание кому-то → ревность/чувство несправедливости → коллектив кромсает себя сам, хотя человек ничего не сделал; прославление начальником = «начало конца» предприятия (управленца перекупили/подмяли); славят вас без реальных дел = ваше сознание берут под контроль
- **Падение Волховского круга (семинар 52):** богов стравили, прославляя одних и принижая других; неверное использование слова «славить» привело к падению круга (см. [[Волховской-круг]])
- Временная парализация управления дала возможность внедрения новых принципов («человек человеку враг»), пассивных излучателей и чаромутения речи/языка/танца/геометрии
- Начало сопротивления = **иммунитет**: вырастить количество людей с внутренним осознанием целостности мира; их излучение подтянет остальных

## Contradictions / Uncertainty
- Status: tentative — связка «прославление → избранность → фашизм» дана как интерпретация ведущего; исторические обоснования (война богов, 2 000 лет изучения) не проверяемы извне
- Гордость позиционируется как «системное качество», но в других семинарах (13, 27) трактуется через избранность/превосходство — требует сверки
