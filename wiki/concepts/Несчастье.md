# Несчастье

## Summary
Следствие выхода с траектории; результат накопления неотработанных событий.

## Current Understanding
- Несчастье = следствие выхода с траектории
- Результат накопления неотработанных событий (корректирующих)
- «Штормит/штиль» — следствие выхода с траектории и накопления неотработанных событий
- Несчастье можно исправить возвратом на траекторию
- Реагировать на первичные сигналы надо сразу; выход без проработки = усугубление
