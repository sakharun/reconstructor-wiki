# Нирвана

## Summary
Состояние, когда человек участвует во всех четырёх траекториях (личная, родовая, общественная, мировая). «Ни рвано» = целостное.

## Current Understanding
- Нирвана = участие во всех четырёх траекториях
- «Ни рвано» = целостное; не конечный вариант
- Целостность распространяется только на то кольцо, где происходило
- Микро-состояния нирваны = ясность в определённом кольце; нет ни зла, ни добра — просто видение событий в рамках ССР
- Обычные существа = материал для чужих рук; развивайтесь, иначе будут использовать
- 90% живущих на планете = материалы
- Материал → Инструмент → Мастер → Заказчик (импульс из Солнца)
- **Нирвана = псевдоцелостное состояние (семинар 34):** сознание прикоснулось ко всем тонким телам и увидело их работу, но никогда не увидит настоящую целостность — не для этого создано; это очень высокий уровень, доступен единицам
- Нирвана для волхва ≠ нирвана для обычного человека — другие категории, другие объёмы сопряжения информации; кольцо — не следующее и даже не через одно
- **Признаки нирваны:** яркое присутствие смысла существования + внутренний комфорт в любом действии + внешнее напряжение
- Нирвана ≠ расслабление: это большая трудоёмкая работа (напряжение, развитие, преобразование, трансмутация, совмещение на разных кольцах несовместимого)
- **Нирвана в конце фрактализации (семинар 112):** нирвана = «нерваное» (псевдоцелое); наступает после прохождения двух свастик (20 качеств); пожилой, проведя фрактализацию через десятку, проходит состояние нирваны
- **Настоящая нирвана — только в изменёнке (семинар 36):** минимум в состоянии сверхсознания, когда реально вмещаешь весь мир; сознание весь мир не вместит — прыгает по фрагментам; состояние «нерваного» (цельного) сознания = псевдоцелостность
- **Нирвана = псевдосостояние (семинар 40):** сознание никогда не достигнет целостности в чистом виде (создано работать с фрагментами) → псевдоцелостность; нирвана = долгий путь естественного прохождения всех этапов на практике (прошло по кольцам до самого верха), в отличие от сердца, которому развитие не нужно (соприкасается со всеми сразу)
