# Правда

## Summary
Правило, подтверждающее право на доминирование через логику сознания. Правда у каждого своя. Правила сознания = «это работает так». Маркер для ССР.

## Current Understanding
- **Правда** = правило, подтверждающее право на доминирование через логику сознания
- Правда у каждого своя (это верно, если понимать суть процессов)
- Правила сознания = элементы, которые правят сознанием
- **«Это работает так»** = статус после совмещения нового качества
- **«Я думаю»** = сознание выдаёт варианты, личность сравнивает; личность не участвует в мышлении
- Личность = производная сознания; сознание = база данных
- Правда = призма сознания, через которую проходит луч внимания
- **Маркер для ССР** — правда = результат, на который смотрит система, выдавая или не выдавая корректирующие события
- Правда поляризована: честь, стыд, совесть直接影响ают восприятие
- Информация в образах = всегда искажена, фрагментарна
- «Ложь» = от «ложить» = поверхностное восприятие
- Расширение сознания → изменение правды
