# Причинность

## Summary
Четырёхступенчатая вертикаль: следствие → причина → условия зарождения причины → причинность. Подсознание работает в зоне следствий, сознание проявляет причину, сверхсознание даёт условия, надсознание — саму причинность. Воздействие на причину даёт максимальный расход потенциала при кратковременном эффекте.

## Current Understanding
- **Подсознание — зона прямых следствий.** «Есть люди, которые в подсознании ищут причины — это заблуждение»
- **Четыре ступени:** следствие → причина → условия зарождения причины → причинность
- **Первая причинность** зарождается в [[Надсознание|надсознании]] и связана с взаимодействием со структурами того же уровня (иные матрицы, как наш мир) либо **следующего выше кольца**
- **Условия формирования причин** заведует [[Сверхсознание|сверхсознание]] — это **возможности реализации первопричины**
- **Сознание = причина:** тот, кто имеет чин; именно сознание проявляет важность этого проявления
- **Ясновидящий работает только в поле причин:** «Вы никогда не найдёте ясновидящих, которые работают в поле формирования условий для причины» (см. [[Ясновидение]])
- **Рекомендация лектора:** «если хотите хоть как-то в чём-то разобраться, выходите хотя бы на **условия формирования причины**» — тогда «гораздо больший по времени интервал» спокойствия
- **Искать причину нужно начинать с себя** — в том числе по корректирующим событиям (см. [[Корректирующие-события]])

### Пример со сварщиком
- Чтобы сварщик сварил конструкцию, руководство должно создать **условия**: спецодежда, оборудование, материал, рабочее место, зарплата, отчисления, страховка. По сути — **возможность выполнить работу с определённым качеством**
- Если привлечь того, кто «за три копейки всё сварит на коленке», качество непредсказуемо; **профессионал** работает в созданных условиях
- **Сварщик как отображение = сознание = причина.** Условия создавал не он
- **Почему все ищут причину:** причина — **этап, фрагмент, видимый для сознания и сознания окружающих**; сознание обывателя не понимает, что это фрагмент
- **Цена:** воздействие на причину даёт **максимальный расход потенциала при кратковременном эффекте**
- Образ изначально отброшен: первичный импульс спущен с Солнца **как задача**, но «рабочее место, страховка, зарплата — не готовы», то есть нет сплетения конфигурации качеств (см. [[Волхв]])

### Пример с больным органом
- **Три проявления:** следствие — боль; причина — сам орган; **условия** — непоступление веществ из другого органа, который сам может не болеть
- **Если идти ещё дальше, в причинность:** выход на **корректирующие события**, которые воздействуют на тонкое тело → тонкое тело отображает процессы на физическое → происходят процессы
- **Статус медицины:** «наши медики в основном лечат следствие. Они убирают боль, они убирают симптоматику»

## Contradictions / Uncertainty
- **Число ступеней:** заявлены четыре, но «как идти ещё дальше» подразумевает продолжение за причинность — конечность вертикали не подтверждена (Status: лакуна)
- **«Воздействие на причину — максимальный расход»** vs прямая рекомендация «искать причину нужно начинать с себя»: скорее речь о применении силы к фрагменту, а не о поиске — прямо не разведено (Status: не сведено)
- **Отнесение «первой причинности» к надсознанию** не согласовано с [[Первая-мысль]] и распределением по уровням стресса (Status: не сведено)
- Механизм «сплетения конфигурации качеств», допускающей реализацию задачи, не описан
