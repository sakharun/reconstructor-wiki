# Стоп-кадр качества

## Summary
Застывание качеств когда-то прошедших по матрице событий на позиции интенсивности. Как только первичная волна прошла по матрице, события остаются «застывшими» качествами — и эти стоп-кадры становятся материалом для будущих версий.

## Current Understanding
- **Механизм:** первичная волна проходит по матрице → события застывают на позиции интенсивности качеств → это **стоп-кадр качества**
- Прошедшие качества не исчезают, а фиксируются; **будущие версии строятся из стоп-кадров прошлых проходов**
- «Мы сами — несменяемые участники… строим своё будущее на тысячи реинкарнаций»: кто был в прошлой версии, участвует в следующих
- Связано с циклом версий: после дохода волны до конца матрицы версия завершается и начинается сначала на базе застывших качеств (см. [[Версия-цивилизации]])
- Образы в новых версиях сильно меняются, но **сетка качеств и отношения не меняются** — образы «одеваются» на тот же стоп-кадр
