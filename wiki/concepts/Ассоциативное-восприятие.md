# Ассоциативное-восприятие

## Summary
Метод восприятия информации сознанием: что-то похоже → продолжение мышления без точного совпадения.

## Current Understanding
- Ассоциативное восприятие = нет точного совпадения с базой, но есть сходство
- Позволяет не останавливать мышление при отсутствии точного совпадения
- Используется в поисках по кольцам (вибрационным уровням)
- Через кольца ассоциация не прыгает — нужно существо из того кольца
- Может давать ложные результаты (ветка похожа на человека)
- Используется для определения: опасно/не нужно, выгодно/невыгодно
- Стереотип: "если много людей — ошибаться не будут"
- Ассоциативная память оценки людей (занятие 46):** человек важен не сам по себе, а события, в поле которых он попадал, и реакции Личности; вспоминается не человек, а картина реакций в событиях; «никогда не суди ни о ком по внешнему проявлению, всегда ошибёшься» (ведущий); немногие, достигнув уровня развития, оценивают мотивацию появления человека в событии (см. [[Память-Личности]])
- **Ассоциация как 2-й режим ума (семинар 48):** когда ум не находит прямой образ, автоматически включается поиск по ассоциациям; качество резонирования; ум прогоняет огромные объёмы базы, личность получает только результат «похоже на то-то» (см. [[Четыре-режима-ума]])
- **Ассоциация = поддержка сознания (семинар 48):** спасает сознание от остановки плетения логики при малой базе; чем больше база знания — тем меньше ассоциаций, быстрее и точнее реакция
