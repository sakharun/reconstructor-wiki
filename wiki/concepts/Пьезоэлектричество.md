# Пьезоэлектричество

## Summary
Электричество, вырабатываемое камнем при циклах сжатия/разжатия. Камень — носитель информации и энергии; храмы строят на камнях.

## Current Understanding
- Камень вырабатывает электричество при циклах сжатия/разжатия
- В камнях зашита информация, заложенная при формировании планет
- Камень поддерживает конфигурацию видов (опыт с лягушками)
- Храмы строят на камнях (источник энергии)
- Жрецы использовали камни для воздействия (удары жрецов)
