# Механизм-загрузки-информации

## Summary
Процесс перехода информации в знание: информация → практика = знание.

## Current Understanding
- Информация (структура управления) → Действие (структура реализации) = Знание
- Чтобы информация стала знанием — нужно провести через практику
- Сознание не проверяет информацию — проверяете только вы сами
- Механизм: память → сравнение → внутреннее доверие → схема загрузки
- 4 типа действий: мотивированное, демонстрируемое, с обратной связью, без обратной связи
- Действие должно быть физическим, видимым сенсорами сознания
