# Отображение

## Summary
Проекция — одно явление проявляется через другое (как книга проявляется через здания).

## Current Understanding
- Отображение = проекция (не противоположное)
- Пример: книга одна, отображений (построенных зданий) — сколько угодно
- Путин = отображение сознания волхва (не сам волхв)
- Сталин = отображение верховного жреца
- Отражение = противоположное (правое-левое, тёплое-холодное)
