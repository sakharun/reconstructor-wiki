# Память генетики

## Summary
Генетическая информация рода, хранящаяся в подсознании. Вся история без искажений.

## Current Understanding
- В генетике есть вся история без искажения
- Вопрос: сможете ли вы распаковать
- Никто не подменил (хотя попытки уже есть)
- Родовые проблемы — это багаж, который может вылезти в любой момент
- Если род что-то не отработал — прикладывает на следующее поколение
- Реинкарнация завязана на род, пока род не выполнит предназначение
- Стыд = проявление памяти генетики
- **Генетика = дубль ведогона (занятие 46):** в генетике содержится вся информация ведогона (личного подсознания); работа с качествами в генетике и работа с ведогоном = доступ в одну базу; ведогон получает качества на порядок быстрее, чем они прописываются в генетике (задержка небольшая по времени); распаковка генетики на 4-м уровне стресса = прямое соприкосновение с ведогоном (см. [[Ведогон]])
