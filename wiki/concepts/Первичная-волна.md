# Первичная волна

## Summary
Информационная волна первого кольца событийной матрицы: единственная в своём кольце, проходит матрицу один раз, задаёт опорную скорость (естественное движение) и несёт весь потенциал. Аналог генератора с тактовой частотой.

## Current Understanding
- **Первичная волна = информационная волна**, а не электрический импульс; электричество = поле, в котором она проходит (см. [[Электричество]])
- **В первом кольце волна одна**; проходит матрицу один раз, задаёт **опорную скорость = естественное движение** (см. [[Естественное-движение]])
- **Генератор:** несущая частота + тактовый генератор-опорник; задаёт интенсивность движения
- **Несёт весь потенциал** — «весь потенциал висит на этой волне» (см. [[Потенциал]])
- Механика запуска: **гладь → провал (задача) → всплеск → движение**; любой нормальный процесс по траектории начинается с провала
- При достижении конца матрицы → **завершение версии**, всё начинается сначала (см. [[Версия-цивилизации]])
- Волна распространяется по кольцам с модуляциями; на «дне» — мельтешение, принимаемое сознанием за начало/конец события (время сознания)
- Порождённые волной процессы = **время сознания** (прошлое/настоящее/будущее); «не рождается всё, а оживает всё»
