# Описание

## Summary
Процесс формирования данных о явлении. Делится на два типа: статическое (результат) и динамическое (процесс).

## Current Understanding
- Описание — это то, как данные формируются
- **Статическое описание** — результат: картинка, геометрия, физика, химия, астрономия, астрология
- **Динамическое описание** — процесс: алгоритм, формула, уравнение, гипотеза, теорема, теория
- Описание формирует данные → данные формируют информацию → информация формирует знание
- Без образов, эмоций и ощущений = основа познания
