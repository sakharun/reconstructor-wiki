# Системное зрение

## Summary
Способность видеть работу системы через алгоритм, не через образы. Отдельный канал восприятия, развивающийся по мере осознания.

## Current Understanding
- Системное зрение = видеть алгоритм, не картинку
- Работает через безобразную информацию
- Развивается, когда человек замечает, как система работает с ним
- Отличается от寻常ного зрения:寻常ное = образы, системное = алгоритм
- Позволяет замечать подмены и управляющие структуры
