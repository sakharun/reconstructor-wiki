# Проекция

## Summary
Несомое (содержание), стабильно-долговременно присутствующее в мире, создаваемое через теневое преломление-чертёж. Мир строится по принципу фрактализации: «отображения» по сути — проекции.

## Current Understanding
- Проекция = **несомое**, создаётся как **стабильно-долговременно** (не вечно) присутствующее в мире
- **Вечность = движение через изменения**; изменения ≠ уничтожение (некоторые варианты изменений сознание воспринимает как уничтожение)
- Проекция = теневое преломление, выглядит как **чертёж**, который проходит стадии уплотнения до материализации детали/объекта
- Объект не существует сам по себе — его изготавливают для цели (первый постулат: «что-то для чего-то существует»)
- Дуальность: у каждого изготовленного есть пара; «моно» = сознание не видит дуальность к объекту (как с «хаосом»)
- Разрушение физическое → переход в информационную структуру; разрушение информационной структуры → начало материализации (цикличные, системные вещи)
- ССР ничего не уничтожает: что появилось — навсегда её строительный материал
- **Мысль создаёт первичную проекцию** того, что должно быть в конце процесса (до конкретики)
