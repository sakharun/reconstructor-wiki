# Линза сознания

## Summary
Линза сознания — один из компонентов сознания (по перечню лектора). Через неё проходит знание, полученное личностью, поэтому она формирует мнение и вектор обработки информации. В семинаре 66 содержание линзы не раскрыто — оно отнесено к одной из предыдущих лекций. Status: tentative.

## Current Understanding
- Входит в перечень **компонентов сознания** наряду с памятью, умом, виртуальным миром, системой самоидентификации, датчиками съёма информации, излучателем информации, базой качества
- **Содержание в этом семинаре не раскрыто:** лектор отсылает к одной из предыдущих лекций («линза сознания описана в одной из предыдущих лекций»)
- Место в цепочке обработки информации по лектору:
  - **информация** → проходит через **практику** → становится [[Знание|знанием]]
  - [[Личность|личность]] формирует **мнение**, которое проходит через **линзу сознания**
  - линза работает через **знания**
  - к информации личность приходит через **интерес**
  - **интерес задаёт траекторию**, а траекторию можно исказить → отсюда необходимость читать [[Знаки|знаки]]
- Связана с [[Поляризация|поляризацией]]: осознанное отношение личности придаёт информации окрас **до совмещения**, то есть поляризует её мнением — это предпосылка [[Осознанность|осознанности]] по факту действия
- Мнение личности **задаёт вектор**; вектор отразится при совмещении и даст обратную связь **через влияние на один из внутренних «магнитов»**, притягивающих к событиям
