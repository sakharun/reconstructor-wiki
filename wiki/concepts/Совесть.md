# Совесть

## Summary
Весть, прошедшая совмещение. Внешняя общественная программа. Основа сообщества. «Совесть = совместная весть» (семинар 32) — механизм сверки доверия к внешней информации.

## Current Understanding
- **Совесть** = весть, прошедшая совмещение
- **Совесть = «совместная весть» (семинар 32):** сравнение полученного вывода с вестью при проверке доверия; совесть сопоставляет вывод с внутренней вестью
- Внешняя общественная программа зарождения и развития общества
- Связана с совмещением родов для взаимодействия на траектории общества
- **Основа сообщества** — человек действует по совести, опираясь на культурные/общественные правила
- Отошедший от правил = бессовестный; раньше закрывались все возможности
- **Традиция** ≠ обычай; традиция = твердь Ра в движении через Ци
- Праздники с обрядом = традиция; без обряда = обычай
- **Весть** = информация от первоисточника; передаётся через веру; несёт структуру, правила, задачу сообщества
- Совесть = производная от чести (честь формирует импульсы → совесть)
- Совесть объединяет роды, но подавляет индивидуальность (без стыда → геноцид)
- Сейчас: суррогат совести; внутренняя культура убирается; внешняя культура на первом месте
- **Внутренние запреты** — одна из дуальностей первичного качества «ограничение» (внутренние запреты = совесть, внешние = законы) — занятие 27
- **Совесть = совместная весть = свод правил (семинар 33):** правила/законы прописываются в обществе; даются верховным жрецом на основе традиций; ни одно общество не организуется само собой — общество = следствие работы жреческо-волховской системы
- **Сейчас совесть (семинар 33):** выглядит как потребительское сообщество в режиме уничтожения планеты, с наплевательским отношением к роду; вытащив внимание из внутренней культуры, человека делают управляемым на ~98%
- **99% населения — «рослые», не взрослые (семинар 33):** у рослого только рост большой, у взрослого взор рослый (видит дальше); выросшее тело ≠ стать взрослым
- **Доверие к себе = переросши совесть (семинар 33):** совесть вмещается как фрагмент на уровне верховного жреца (см. [[Доверие]], [[Доверие-себе]])

### Совесть и жрецы (занятие 54)
- **Совесть = совместная весть = совместившаяся весть:** склеенные воедино правила; обычаи и традиции «нанизаны на одну нитку»
- **Создавший совесть по своей конфигурации получает твёрдый контроль над поселением** — совесть = одна из уязвимостей для управления
- **Над формированием совести всегда стояли жрецы:** делали выборки из того, что давали волхвы (жрецы = сами под волхвами); «традиция ≠ обычай» (традиция = то, что давали волхвы)
- **Переписка совести:** внедрение и изменение правил базируется на способности переписать «весть»; примеры — Европа 90-х («гей» = неприязнь → сейчас иначе), ювенальная юстиция; везде вплетается «совместная весть» под текущие программы
- Стыд, самоконтроль, ответственность — элементы совести как правила; «бессовестный» = отошедший от правил (см. также [[Стыд]])
