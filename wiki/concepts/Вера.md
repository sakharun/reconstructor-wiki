# Вера

## Summary
Внутренний мотиватор к действию. «Я верую» = осознанное намерение по траектории на основе знаний о Коне. Ве = внутреннее, РА = первоисточник.

## Current Understanding
- Вера — внутреннее движение божественной информации (света)
- **Ве = внутреннее, РА = первоисточник, истина, мысль**
- «Я верую» = осознанное намерение по траектории: «Я такой-то, находясь в трезвой рассудке, намереваюсь сделать действие в определённом событии, согласно знания о принадлежности события к траектории»
- **Доверие ≠ Вера**: доверие — мотиватор с внешним источником (информация для логики сознания); слабая точка сознания = доверие; манипуляторы используют это
- Вера = Возможности (один из четырёх элементов Троицы)
- «Люди богу ведающие» = осознанно дающие внутри себя проходить импульсу
- Познать Бога невозможно — если познал, ты уже Бог, а он поднимется выше
- **Вера — противоположность доверия:** вера = внешнее напряжение + внутренний комфорт (состояние на траектории), целостное, изнутри, отношение к работе тонких тел; доверие = внешний комфорт + внутреннее напряжение, фрагментарное, извне, физиология (семинары 33/34)
- Вера согласована высшими инстанциями и учтена в мере (план развёртки) → минимум корректирующих событий; доверие подсознание с мерой не сверяет
- Первичная информация (план, истина, первопричина, божественный свет) материализуется только через внутренний мир существа, поляризуя сознание на действия (семинар 34)
- Чем чище проводник, тем быстрее и ярче материализация через веру («по вере вашей дано вам будет» — в прямом, не искажённом смысле)
- Вера ведёт к готовности принимать импульс от Волхва
- Сознание устроено так: если ему не показать — оно не будет работать; «ни одно существо не может развиваться, пока более высшее не обратит внимание»
- Когда дали информацию через практику — сознание вынуждено взаимодействовать; после совмещения — другая призма восприятия
- **Вера = сверхсознание, информационная база внутри; доверие = сознание, база снаружи (семинар 32):** доверие — сравнение памяти с внешней информацией, сверка вывода с «совместной вестью» (совестью); вера — отношение к работе тонких тел
- **Доверие = общество, вера = индивидуальность (семинар 32);** доверие к себе возможно только переросши совесть (уровень верховного жреца)
- **Право веры vs право вести веру (семинар 32):** жильцы имеют право веры (верить словам жреца), правоверы — право нести веру (Ве = внутреннее движение, Ра = свет/первичная задача) — см. [[Право-веры]], [[Правоверы]]
- **Лжевера (семинар 33):** = вторая воля с её информационной базой; вера в реальном проявлении практически под контролем лжеверы; лжевера делает веру фрагментарной и внешней — см. [[Вторая-воля]]
- **Молитва = программа (семинар 33):** работает только при степени доверия; «по вере вашей дано вам будет» — буквально: чем чище проводник, тем быстрее материализация; искренне читающие молитву «Отче Наш» продвигают доминирование паразита — см. [[Молитва]], [[Молитва-Отче-Наш]]
- **Вера vs Доверие — онтогенез (семинар 112):** ребёнок живёт на доверии (базы нет, выбора нет); постепенно накапливает знания и переходит из доверия в веру; религия говорит о вере, но живёт доверием; вера = внутреннее движение первоисточника, доверие = внешнее принятие
