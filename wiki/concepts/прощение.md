# Прощение

## Summary
Отсрочка, передышка, вход в цикл (событие повторится).

## Current Understanding
- Прощение — передышка на определённое время
- При прощении событие повторится без усугубления
- Прощение — вход в цикл
- Прощение не решает проблему, а откладывает
- Себя можно только оправдать, не простить
- Прощение — процесс изнутри, не мозгами
- **Прощение долга = вынимание из корректирующего события (семинар 33):** прощённый уходит от события, но оно повторится — с наслоением (см. [[Долг]])
- **«Если разобраться с событием полностью — прощать будет некого» (семинар 33):** прощение = медвежья услуга; исключение — помощь деньгами при требовании проработки (желательно при вас)
- **Бог никогда никого не испытывает (семинар 33):** «испытание» = корректирующие события при нарушении меры; прощение не снимает отработку (см. [[Корректирующие-события]])
