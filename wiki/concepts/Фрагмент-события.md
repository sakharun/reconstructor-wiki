# Фрагмент события

## Summary
Деление события на части для осознания. Начало-конец = точка опоры/отдыха для сознания. Без фрагментации → депрессия (даже в позитивном событии).

## Current Understanding
- Событие фрагментируется специально — для осознания
- Фрагмент = микро-событие с началом и концом
- Начало-конец = точка опоры, стабилизация, «отдых» для сознания
- Без фрагментации → «течь крыша», глубокая депрессия (независимо от позитивности)
- На траектории фрагменты расположены последовательно → иллюзия «всё хорошо»
- Сошёл с траектории → фрагменты непоследовательны → «горе началось и не заканчивается»
- Событие заканчивается, когда пройден полный спектр → качество наработано → выплёвывает
- Конфликт → 0,05% наработки → следующий фрагмент с учётом этого → постепенное ослабление
- Можно ускорить: пройти 3-4 фрагмента за один; нужно тянуть человека рядом
