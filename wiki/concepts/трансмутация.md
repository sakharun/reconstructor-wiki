# Трансмутация

## Summary
Изменение генетики при стрессах, ведущее к смене вибрационной ниши.

## Current Understanding
- Трансмутация — изменение генетики при серьёзных стрессах
- Род проходит события со стрессами → изменение генетики
- Ведёт к смене вибрационной ниши (род не может быть носителем одной вибрации)
- «Люди с одного лукошка» могут генетически различаться из-за трансмутации
- Генетика может мутировать в процессе определённых процессов
- Англосаксы — носители 2-й воли (на данный момент)
- Негры — воины с разрушенной планеты (не местные); адаптированы к жаре, агрессивная генетика, поселены на экваторе; вибрационные отличия большие
- Трансмутация также = переход на следующий уровень людей (подсознание → сознание)
