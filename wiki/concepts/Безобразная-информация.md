# Безобразная информация

## Summary
Информация без образов, без эмоций, без ощущений. Описывает систему саморегуляции (алгоритм). Основа познания — образы подменяют знание.

## Current Understanding
- Безобразная информация = без форм, без картинок, без эмоций
- Описывает алгоритм системы саморегуляции
- Образы, эмоции, ощущения — это подмена знания, отвлекают от алгоритма
- Без образов = основа познания; с образами = ложное восприятие
- Человеку свойственно мыслить образами — это неправильный путь
- Системное зрение работает с безобразной информацией
