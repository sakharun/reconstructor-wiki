# Естественное движение

## Summary
Первичное движение — структура среди первичных регуляторов (схем Кона), запускающая и поддерживающая все процессы. = первичная волна первого кольца, «тактовая частота» матрицы; несёт весь потенциал; базируется на «электричестве» как среде. Основа времени (первый из четырёх элементов).

## Current Understanding
- Естественное движение (для технарей — **первичное движение**) — структура среди первичных регуляторов = схем Кона; запускает и поддерживает проявление
- Связано с корнем «есть» («я хочу есть» = «я хочу естественного»; естествознание)
- **Универсальная субстанция**, несущая все вселенские процессы; на виду у всех и одновременно невидимая; первооснова движения любых процессов
- В ней запускаются **волновые процессы, создающие иллюзию циклов** для сознания (псевдоциклы: начало/конец событий); на этой иллюзии строится наука
- **Первичная волна** первого кольца проходит матрицу один раз, задаёт опорную скорость = естественное движение; это движение целого
- Аналогия **генератора:** несущая частота + тактовый генератор-опорник; первичная волна задаёт интенсивность движения, **весь потенциал висит на этой волне**
- Волна: **гладь → провал(задача) → всплеск → движение**; любой нормальный процесс по траектории начинается с провала; начало с подъёма = к неуклонному спуску
- Дальше по кольцам волна получает **модуляции**: подъёмы-спады, на дне — «мельтешение», которое сознание принимает за начало/конец события
- Порядок: впереди гладь, сзади гладь — «одна опорная волна проходит, на неё всё опирается»
- **Волна зарождает версию, жизнь, прошлое/настоящее/будущее, смерть для сознания и бессмертие** (существует в постоянном повторе)
- Когда первичная волна первого кольца доходит до конца матрицы — заканчивается версия, всё начинается сначала
- **Первичная волна = информационная волна** (не электрический импульс); электричество = поле, в котором волна проходит
- Естественное движение = первичное движение, **движение = жизнь**; «время сознания» опирается на следствия этой волны (движение планет, электронов) — см. [[Время]]
