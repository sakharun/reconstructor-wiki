# Многополярный мир

## Summary
Организм, где каждый орган (страна) имеет свой источник поляризации, притягивающей свой материал для выполнения своей функции. Противоположность — однополярный мир: механизм, убирающий возможность видеть своё предназначение, т. е. усреднение и порабощение индивидуальности через сознание.

## Current Understanding
- **Определение (семинар 80):** «Многополярный мир, если перевести на простой язык, — это организм, где каждый орган имеет свой источник поляризации, притягивающей свой материал для выполнения своей функции в организме»
- **Полярность = полюс:** «Полюс — это то, что имеет потенциал поляризовать вокруг себя то, что входит в спектр поляризации» — на этом работает «магнит, который втягивает нас в события, исходя из конфигурации качеств» (см. [[Поляризация]], [[Четыре-магнита]])
- **Однополярный мир:** «Как только речь заходит об однополярном мире, это значит, речь заходит о создании механизма, убирающего возможность кем-либо — человеком или страной — видеть своё предназначение, а значит, исполнить его» (см. [[Предназначение]])
- Механизм однополярности: «идёт определённое усреднение, работа только через сознание. То есть к такому можно привести только через порабощение индивидуальности, через сознание» (см. [[Личность]], [[сознание]])
- **Безразличие как итог:** «Когда человек лишается смысла, он входит в состояние "воля-неволя"… это приблизительно безразличие. Безразличием он не живёт. Он существует. Таким и управлять легче, и "доить" легче» (см. [[Смысл-жизни]], [[Неволя]])
- **Материал для каждого полюса:** страна «отображает определённый орган», а «рождение человека в определённой стране совершенно не случайно: определённая база качеств будет соответствовать именно этой стране» → традиции, обычаи, религии «будут под поляризацией предназначения этой страны» (см. [[Страна]], [[Рождение-цивилизации]])
- **Практическое следствие — экономика:** «построить эту мировую структуру… которая будет согласовывать работу всех этих разношёрстных экономик»; экономики «должны разниться… поскольку она будет связана с индивидуальностями проявления этой страны» — противоположность «одну экономику везде одинаково "фигачит"» (см. [[Бизнес]], [[Государство]])
- **Позиция лектора о Президенте:** «Только наш Президент — за многополярный мир… именно он… топчет за многополярный мир» (Status: позиция лектора)
- Связь с двумя моделями: многополярность = сообщество-организм («мы строим сообщество, которое, по сути, является организмом»), однополярность = «контролируемую извне донорскую структуру, когда донор ты поневоле» (см. [[Сообщество]], [[Общество]], [[Внешнее-управление]])
