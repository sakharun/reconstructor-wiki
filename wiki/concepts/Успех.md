# Успех

## Summary
У-дача — процесс, когда природа даёт что-то для использования потенциала. Не халява, а боеприпасы для выполнения предназначения.

## Current Understanding
- Успех = у-дача; «удача» от «у-дачи» (процесс, когда что-то дают)
- Природа ничего не даёт просто; халявы не бывает
- Если сразу всё хорошо — не совсем хорошо (потенциал для использования)
- Удача = боеприпасы для солдата перед боем; боеприпасы дают для выполнения действия
- В быту это растягивается на время; обычный человек не ловит логику
- Когда дают что-то (деньги, связи) — не используйте по своему усмотрению; это потенциал для предназначения
