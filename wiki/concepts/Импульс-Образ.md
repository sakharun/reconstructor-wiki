# Импульс-Образ

## Summary
Два разных явления: импульс приходит изнутри без формы, образ формируется сознанием.

## Current Understanding
- **Импульс** — изнутри, без образа, без обоснования. Просто: "надо делать то-то, идти туда-то"
- **Образ** — работа сознания, с обоснованием, логикой
- Сначала импульс + потом логика = сверху (задача от системы)
- Сначала логика + потом обоснование = сознание (не от системы)
- Вторая воля тоже приходит как импульс — нужно различать, чей импульс
