# Информация

## Summary
Иная форма ци (первичного целостного). Не данные и не следствие, а сам процесс проявления. Формулировки единой нет — каждая раскрывает своё. Бывает прошлая (происшедшее) и будущая (запланированное); настоящее невозможно описать.

## Current Understanding
- Информация — иная форма ци и я
- Ци — описание целостного; информация — фрагментарная часть
- Информация заведомо фрагментарна — не несёт гармонии
- Каждый фрагмент нарушает меру
- С информацией способно работать только сознание
- Информация выходит через Солнце (Ра) и постепенно уплотняется
- При разрушении информации рождается пространство; при разрушении пространства — информация
- Информация через нас → желание, намерение, стремление (вера)
- **Информация = процесс, а не следствие**
- **Прошлое** = происшедшее; **будущее** = запланированное; **настоящее** невозможно описать
- **Иное** = непознанное, неизвестное; **другое** = известное, противоположное. Человечество подменяет «другое» на «иное»
- **Три типа информации:**
  - **Первичная** — иная форма, целостная, минимум искажений; при разрушении пространства обнажается и уходит в Антимир
  - **Управляющая** — структурная, системная; описывает целостность для своего кольца
  - **Реализующая** — образная, фрагментарная; работает в пространстве
- **Азбука** — начало реализующей информации (не сама реализующая!)
- **Без образов** = основа познания; образы, эмоции, ощущения = подмена знания
- **Мир = программируемая информационная среда (семинар 33):** пространство = следствие информационных процессов; распад материала = выход информации, распад информации = материализация (см. [[Покой]])
- **Информация vs материализация (семинар 33):** покойник = пошёл в процесс распространения/фрактализации информации; цикл «распад материала → информация; распад информации → материализация»

### Семинар 73: череда образов; пересборка; буферная зона
- **«Информация — это обычное сочетание звуков и образов, к которым прикреплены описательные процессы, имеющие замкнутую через кольцо логику… бесконфликтную логику для сознания, которая… формирует сверхстабильные образы-клише, исходя из которых идёт реакция через действие. Мы это называем реакцией на информацию»**
- **«Всё, что мы называем информацией, — это череда определённых образов, которые сознание воспринимает как естественные»** (см. [[Образ]])
- **Заблуждение о передаче:** «Многие уверены: когда они что-то рассказывают, они прямо передают информацию собеседнику. Но это иллюзия… Слушатель на основе услышанных слов строит свои собственные образы — из своего опыта, своих ассоциаций, своих фильтров. **Получается не передача, а скорее „пересборка“: один человек запускает цепочку, другой собирает из неё что-то своё**» (см. [[Лов-образов]])
- **Буферная зона:** «Информация почти в чистом виде находится в буферной зоне механизма-преобразователя, который с одной стороны — Солнце, с другой — чёрная дыра… **У нас информации в нашем мире в чистом виде быть не может. Может быть только процесс, отображающий её работу**» (см. [[Тверь]], [[Солнце]])
- **Зона информации и зона реализации:** «Есть зона информации — это управление, есть зона реализации — это пространство. Из информации собирается пакет и в виде импульса подаётся в зону пространства. Здесь он попадает в среду для пространственной реализации» (см. [[Пространство]])
- **Вибрация — разрушающийся информационный пакет:** «вибрация — это информационный пакет в стадии разрушения для перерождения в пространство… самое плотное состояние информации» (см. [[Вибрация]])
- **Информация — сеятель:** «информация — это сеятель, вибрация — это семя, эфир — это поле, образ — это растение» (см. [[Эфир]])
- «Благодаря вибрациям существует плотность химических веществ и их взаимодействие. Но… в основе начала любой вибрации, любого вещества или действия лежит информация»
- **«Наука до сих пор не знает» реальной информации:** «Для обычного человека информация — это льющаяся на нас информация»
- «Сознание не может работать с чистой информацией, оно не для этого создано… есть изменёнка, только через изменёнку можно работать с информацией, и там сознание является наблюдателем» (термин «изменёнка» не раскрыт)
