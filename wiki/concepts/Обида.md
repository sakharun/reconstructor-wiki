# Обида

## Summary
Системное качество с нормой интенсивности. Нормальный человек решает проблему внутри ~2 часов; залипание дольше = проблемы (знахари оформляют это как «грех»).

## Current Understanding
- Обида — системное качество с определённой нормой интенсивности
- Нормальный процесс: осознание → раскаяние → изменение действий (~2 часа)
- Залипание на обиде дольше нормы = проблемы (внутреннее напряжение, конфликты)
- Знахари оформляют залипание как «грех» (религиозная интерпретация системного процесса)
- Прощение без понимания события = выход без усугубления, но событие повторится с наслоением
- «Простив долг» оказываешь медвежью услугу — вынимаешь из корректирующего события
