# Прикосновение (зов)

## Summary
Первый этап объединения: кратковременный импульс из Антимира через Солнце, воспринимаемый ведущим и адаптируемый через его тонкие тела для остальных. Касается только носителей знаний с наработанными качествами.

## Current Understanding

- Зов идёт **из Антимира через Солнце** (солонце) — вся первичная информация для реализации
- Зов — **кратковременный импульс** из набора качеств, составленных в ритмический рисунок
- **Воспринимается ведущим** (начальником/богом) первым; через его тонкие тела адаптируется
- Остальные **не слышат прямой зов**; слышат только после переработки ведущим
- Зов касается **только носителей знаний** (наработанные качества) — второй отсев
- Ведущий всегда **минимум через кольцо**; его логика/приказы не всегда понятны сознанию
- Доверие ведущему — через **внутренний отклик**, а не через логику («не знаю этого человека, но чувствую доверие»)
- Пока идёт событие под ведением — сознание бунтует; внутренний покой сохраняется; результат показывает правоту

### Аналогия на предприятии
- Управленцы (из Антимира) → руководитель (старший мастер) получает документы → адаптирует для рабочих
- Рабочие по фрагментам собирают (электрики, механики, водопроводчики)
- Каждый считает свою профессию главной → конфликты (этап 2)
