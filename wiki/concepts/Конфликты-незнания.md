# Конфликты на основе незнания целого

## Summary
Второй этап объединения: конфликты между участниками из-за непонимания вклада каждого в общее дело. Каждый считает свою профессию/качество главным. Снимается через наглядное понимание значения каждого для целого.

## Current Understanding

- **Причина:** каждый участник ценит своё качество (профессию) выше чужих
- Проявляется на всех уровнях: предприятие, семья, сообщество
- **Пример на предприятии:** электрики vs механики; каждый требует больше зарплаты/отпуска/доплаты
- Конфликты — «как две конкурирующие фирмы» (ревность к проявлениям на заводе)
- **Решение:** экскурсия по всему предприятию — повышение значимости каждого через понимание целого
  - Это и есть **изменение мировосприятия и мировоззрения** по отношению к предприятию
- Конфликты снимаются не запретами, а **наглядным проявлением значения каждой профессии**
- **Пример из жизни лектора:** Алчевский металлургический комбинат — на большом предприятии совмещение идёт естественно; на малом — может не наступить (1,5 года без изменений)
