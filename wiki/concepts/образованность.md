# Образованность

## Summary
Передача информации без искажений, умение вытаскивать образы из другого.

## Current Understanding
- Образованность — передача информации без искажений
- Образованный — тот, кто вытаскивает образы из другого
- Не образование (грамота), а образованность
- Образ — звать (образованный — тот, кто может у другого выбрать нужный образ)
- При разговоре ты разговариваешь сам с собой (свои образы)
- Чтобы донести свой образ, нужно вытащить образы из собеседника

### Семинар 73: «образ через зов нести»
- **«Качество „образованность“: образ через зов нести, а посредством вас — для вас, но с потребностью для себя»**
- **«Вы никогда не донесёте человеку информацию в стереотипном понимании, если у него не будет той базы, из которой нужно словом ловить определённые образы. Поэтому прежде чем давать картину из мозаики, нужно дать описание применяющихся элементов в этой мозаике»** (см. [[Лов-образов]], [[База-вибраций]])
- **Пример с чемоданом:** «у каждого автоматом в вашем виртуальном пространстве возникает свой чемодан. И чтобы донести свой, я должен дополнительно ввести описание цвета, фасона, размера… **Образ буду звать**» (см. [[Образ]])
- **Иностранный язык:** «пока в вашей базе не будет формы звучания слова и его понимания через образ, ни один иностранец из вас нужный образ не вытянет… информационный обмен как диалог не состоится»
- **Профессиональные слова:** «любое профессиональное направление имеет свои чёткие, прописанные специфические слова»; лектор: «я вам собираю описание мозаики… только после этого… я буду говорить, например, „процесс передачи информации“ — у вас будет возникать именно тот процесс, который я сейчас описал»
- **«Образованными должны быть учителя, педагоги, воспитатели, лекторы — все те, кто в работе соприкасаются с потребностью донесения нужного образа с минимальными искажениями. Заметьте, не информации, а образа, хотя по привычке мы будем ещё долго называть это информацией»**
- Передача = «пересборка»: «слушатель… строит свои собственные образы — из своего опыта, своих ассоциаций, своих фильтров… один человек запускает цепочку, другой собирает из неё что-то своё» (см. [[Информация]])
- «Образ буду звать» ↔ «волна ловит потенциал» — «волна — это аналог слова, но в другом кольце» (см. [[Волна]], [[Эфир]])
