# Чёрная-дыра

## Summary
Глобальный процесс связи между мирами; канал для информации от антимира. Информация идёт через солонцы и тёмные дыры (глобальные процессы).

## Current Understanding
- Чёрная дыра = глобальный процесс связи между мирами
- Канал для информации от антимира
- Информация идёт через солонцы и тёмные дыры (глобальные процессы)
- Связана с понятием «портал» между измерениями
- **Место полного разрушения материала (занятие 39):** в чёрной дыре идёт полное разрушение материального; с другой стороны выходит информация и переходит в мир (то, куда уходим после смерти)
- **Коловрат = круглые ворота (занятие 39):** из солнца выходит информация из антимира через круглые ворота (Коловрат: коло = круглое, врат = врата); чёрная дыра — те же ворота, только с другой стороны
