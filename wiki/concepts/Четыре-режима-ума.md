# Четыре-режима-ума

## Summary
Четыре способа сравнения, через которые работает ум как элемент сознания: прямое, ассоциативное, с дополнением, с преобразованием. Категории от качества: ограничение (прямое), резонирование (ассоциативное), желаемый каркас (с дополнением), исследование (с преобразованием).

## Current Understanding
- Ум работает через четыре режима сравнения (не «находится» в одном из качеств): 
  1. **Прямое сравнение** — мгновенная идентификация без преломления; качество ограничения; постоянный режим с полу-рассеянным вниманием; забирает до ~60% работы ума; даёт сверхстабильность идентификации среды («вы понимаете, где вы, без акцента внимания»)
  2. **Ассоциативное** — поиск по сходству, когда прямого образа нет; качество резонирования; запускается «командой» личности при выходе из стабильности первого режима; ум прогоняет огромные объёмы базы («терабайты»), личность лишь получает результат «похоже на то-то»; спасает сознание от остановки плетения логики; чем больше база сознания — тем меньше ассоциаций
  3. **С дополнением** — ум выдал результат, но сознанию не хватает базы вплести его в логику → личность строит «каркас желаемого», результат обкладывается ассоциациями к каркасу; рождаются теории/гипотезы/профессии («теория, притянутая за уши»); **недоработка спектра**: знание не прошло практику, обязательно проверяется реальными событиями
  4. **С преобразованием** — исследование фрагмента до логики без вопросов (по трём деталям двигателя — полный чертёж); ум работает на сбор пазлов через поиск ошибок в логике, а не через желаемое; человек осознанно разваливает свою теорию; уход от стереотипов и авторитетов → сверхиндивидуальность
- При освоении 4-го режима ум работает во всех четырёх одновременно → нагрузка уровня 4-го стресса → кратковременные депрессии и пересборка ориентиров
- Категории качества: 1 = ограничение (сверхстабильность), 2 = резонирование (стабильность/удобство), 3 = желаемая нравственность (каркас), 4 = поиск ошибок (отсутствие вопросов)

## Contradictions / Uncertainty
- Граница между ассоциативным режимом и «с дополнением»: второй начинается с отказа от первого результата, а не с его отсутствия
- Доля «~60%» у прямого режима — оценка, меняется ли с ростом базы?
