# Звук

## Summary
Транспорт для прохождения света Ра к полной материализации. Звук — часть системного процесса, не обособлен. Включает вибрации и волновые процессы. В начале всего — музыка.

## Current Understanding
- Звук = транспорт для прохождения света к материализации; часть системного процесса
- **Механизм (занятие 39):** вибрация (дух) порождает волну; на волны «подсаживаются» информационные пакеты (вибрации с модуляцией) → кристаллизация → материя
- **Аналогия радиопередатчика:** генератор = дух (формирователь ниши) → передатчик = волны → детектор = Демиург → приёмник = мир для ушей (душа)
- **Суть создаёт волну** как импульс (камень бросили в воду); волна постоянна (траектория); качество (наполнение) может меняться → внутренние изменения = информационные пакеты на волнах → формирование внешнего мира
- **Путь = волна, мысль = вибрация** (вибрация создаёт волну; иногда волна порождает вибрацию)
- Иерархия звука: музыка (16-й уровень, сама для себя) → стих (16→1, управленческий инструмент) → слово (с 12-го уровня, тайное) → речь (дуальность слова) → проза (исполнение/реализация) → разговорная речь (намерение через образ)
- Телепатия не отменяет звук: у телепатических цивилизаций звуковое сопровождение мощнее в несколько раз
- Дух = процессы до восприятия уха; душа = «для ушей» (Д-УШ)
- Тело звука — тонкое тело, отвечающее за восприятие первичной музыки; работает с сознанием только при определённом уровне развития
- В камнях зашита информация, заложенная при формировании планет
- **Спектр** нового: «что-то новое пришло — готовьтесь, будет прохождение спектра; в спектр входит всё»
- Кровь считывает информацию в радиусе ~40 м; здание транслирует волновые процессы на определённое расстояние
