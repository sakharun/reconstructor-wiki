# Сознание-и-информация

## Summary
Связь между сознанием и информацией: сознание = механизм совмещения знаний; информация = структура управления.

## Current Understanding
- Сознание = механизм совмещения знаний (информация, проведённая через практику)
- Информация = структура управления; действие = структура реализации
- Информация → действие = знание (механизм загрузки)
- Сознание не проверяет информацию — проверяете только вы сами
- Сознание не может игнорировать информацию: попав «в вилку» сравнения, ищет логику
- При попадании удобной логики извне — принимает без сопротивления (замыкание круга)
