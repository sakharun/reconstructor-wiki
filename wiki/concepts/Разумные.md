# Разумные

## Summary
Четвёртая категория родства, отличная от крови, души и духа. «Я их назвал разумные. Если более полно — это вместившее в себя всё». Ум работает с базой целого; «их невозможно описать через качество, они по сути целые».

## Current Understanding
- **Определение:** категория, «вместившая в себя всё» (достигает масштаба «вместить в себя завод», «вместить в себя Галактику» — по аналогии лектора о заводе).
- **Отличие от [[Эзотерик|эзотерика]]:** эзотерик — *псевдо*целостный элемент (система может использовать его одного вместо целого сообщества); разумный — не псевдоцелостность, а **доступ к общей базе**: «их ум имеет возможность работать с базой целого».
- **Ограничения описания:** у категории нет обычного имени; «невозможно описать через качество» — они по сути целые.
- **Встречаемость:** крайне редкая, «скорее всего только в определённых процессах, связанных с определёнными процессами в самой матрице».
- Лектор относит себя к структуре, где «родство по крови, по душе и даже по духу не имеет никакого значения» — то есть к зоне разумных/целых.

- **Status: tentative.** Второе название категории, по собственному признанию лектора, не дано; количество «неизвестно» («даже не знаю, сколько их вообще существует, когда не появляются»).
- Отношение «разумные» к [[Разум|разуму]] (семинар 48: разум = работа ума в изменённом состоянии с Ра) не установлено.
