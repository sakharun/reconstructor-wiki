# Единение (түмсүү)

## Summary
Кратковременное сращивание сознаний для решения сиюминутной задачи. Низшее проявление качества «объединение». Работает с фрагментом, живёт недолго, запускается любым сознанием.

## Current Understanding
- Единение — кратковременное сращивание сознаний для создания рабочего организма, способного решить задачу и спокойно развалиться
- Замкнуто на кратковременную задачу, которая отзывается для сознания как приоритетная в точке времени и пространства
- При единении минимум конфликтов и максимум позитивных эмоций — люди не успевают узнать друг друга, сознанию не за что зацепиться
- Работает с фрагментом, не имеет логики начала и окончания
- Запускается любым сознанием (уровень развития не важен для начала процесса)
- Единение не работает с глубинными процессами
- Процесс всегда замкнут на кратковременную задачу
- Отсутствует этап совмещения (обязательный для объединения)
- **Мужское начало:** единение — отображение мужского начала, поскольку оно фрагментарно и работает с фрагментами

### Примеры единения:
- Сбор денег на операцию
- Уборка улиц от мусора
- Митинги (в поддержку/против правительства)
- Майдан
- Дружеские компании, которые распадаются
- Семинар (собрались, послушали, распределились)
- Конфетно-букетный период в отношениях
- Любовники без образования семьи (встречаются для точечного удовольствия)

### Длительность:
- От нескольких часов до нескольких месяцев
- Далее — распад или переход в состояние объединения

### Ловушка единения:
- Люди получают «кайф» от единения (хорошее настроение, позитив, никто не набил морду)
- После призыва «давайте объединимся и мир спасать» — начинается втягивание в объединение без понимания последствий

- **Лава образуется только через единение (семинар 52):** масса-лава (побег из концлагеря, паника, свержение правительства, оранжевые революции, казачья лава) = сращивание сознаний под единый информационный импульс извне; ум в лаве переключается в режим сравнения большинства с меньшинством; устоять/возглавить может обладающий качествами управленца (см. [[Лава]])

### Единение как среда знакомства (занятие 54)
- **Единение = низшая форма соединения:** создатель среды для знакомства между будущими объединяющимися; «будущие объединяющиеся знакомятся в этих местах»
- **Единение обязательно проходится перед объединением** (статус: так описано в занятии 54; подтверждает вопрос из «Next Questions» про обязательность этапа)
- **Объединение = серьёзный целостный организм** (не просто форма единения); зов встраивает подходящих в событийный ряд с учётом их траектории (см. [[Зов]], [[Два-зова]])
- **История команды через фазы:** первичное соприкосновение (все «в экстазе») = единение → заход за единение = объединение → конфликты (ругань, «раскусили друг друга») → организм → приходит начало извне или проявляется через реальное событие с потерями (см. [[Событие-вычленения]])
- **«Не бежать толпой»:** услышавших зов не нужно втягивать через единение в объединение толпой — зов селективен, откликается только подходящий (см. [[Отклик]])
- Возбуждение толпы по зову, не предназначенному для неё = не путь объединения («одни возбуждаются, а вы не понимаете, что они нашли — лезть не стоит»)
