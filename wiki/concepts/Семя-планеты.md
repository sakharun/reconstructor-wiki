# Семя-планеты

## Summary
Минерал, приходящий извне и несущий геном планеты-«мужской особи». Падает в зону гор («в матку»), вызывая через пьезоэффект электрический импульс, соединяющий два генома. Межпланетный обмен («плевки» планет) предсказан расчётами Черняева.

## Current Understanding
- **Семя** = минерал извне, несущий информацию генома планеты (мужской особи); обязательное условие — падение в зону гор, устойчивую вибрационную систему («в матку»)
- **Пьезоэлектрический эффект:** при падении в горах (породы с пьезоэффектом) происходит толчок → электрический импульс → движение горных массивов → постоянный поток импульсов → **электрохимическое соединение информации двух геномов**
- **Обмен генетическим фондом планет:** планеты «выплёвывают» булыжники; расчёты Черняева предсказывали места и время (принимались за метеориты); подтверждено примерами («плюс-минус два дня»)
- **Челябинский метеорит** = «не улетел»: на планете действует система ПВО предыдущей версии, сбивающая объекты определённой скорости/объёма
- Обмен между планетами **не только для зачатия** — идёт пересылка пакетов (информация + материальное); процессы нарастают
- Следующий этап выброса воды планеты связан с введением нового подвида; Черняев указывал на усугубление процессов обмена

## Contradictions / Uncertainty
- Что именно за «булыжники» и почему несут геном — не раскрыто
- Система «ПВО предыдущей версии» на планете — предположение лектора
- Граница между «выплюнутым семенем» и обычным метеоритом — по расчётам Черняева, не по инструментальной науке
