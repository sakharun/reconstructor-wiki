# Эпидемия

## Summary
Заболевание и эпидемия как **знак для цивилизации**: важно не «кто виноват», а «какой знак проявился». В лекции 59 названа четвёртым уплотнением; выход — прививка плюс работа над причинами.

## Current Understanding
- **Заболевание и эпидемия = знак для цивилизации**; неважно, кто его запустил: ССР действует **только нашими руками, ногами, головами**
- Смотреть нужно **не с позиции «кто виноват», а с позиции «какой знак проявился»**
- **Четвёртое уплотнение** — такое проявление; если из него не выйти, дальше будет **ещё более серьёзное уплотнение** (то есть ещё более серьёзное корректирующее событие)
- **Выход из события** — сделать прививку ([[Вакцина]]), но этого мало: ССР реагирует **только на внутренние изменения** → сначала прививка, потом работа над причинами
- **Принцип сохранения жизни:** при массовой смертности «сидеть и переосмысливать можно не успеть» — сначала сохранить жизнь и привести организм в состояние, когда можно работать через осмысление
- «Не суди о человеке по внешнему проявлению — всегда ошибёшься»: попавшие в реанимацию оказываются «крайне положительными с точки зрения общества» → небольшое доминирование качеств [[Вторая-воля|второй воли]], которое человек не фиксирует даже для себя
- Связано с [[Корректирующие-события]] (уплотнение = эскалация), [[Знаки]], [[Вирус]], [[Система-саморегуляции]], [[Доминирование]]
