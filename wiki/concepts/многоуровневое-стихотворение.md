# Многоуровневое стихотворение

## Summary
Стих, раскрывающийся на разных уровнях при каждом перечитывании.

## Current Understanding
- Многоуровневое стихотворение = стих, который раскрывается глубже с каждым разом
- Через месяц — видишь другое, ещё через месяц — ещё глубже
- Через 2 года — ещё глубже
- Поэты = работают через стихотворения на информационную среду
- Поэты = работают на сознание (лирика, природа)
- Отличить: плоские стихи vs. многоуровневые
- Пушкин = хранитель определённой разновидности речи, работающей с пространством
