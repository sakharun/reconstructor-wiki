# Ритмическая схема

## Summary
Третья ступень лестницы ритма: ритмическая структура «в поле качеств», образа не имеющая, работающая в событийной сетке (в сетке, которую называют сверхсознанием). К ней подбирается ключ — рифму творящего слова.

## Current Understanding
- **Место в лестнице:** «1. первичный ритм → 2. ритмическая формула → 3. ритмическая схема → 4. ритмический рисунок» (семинар 79, см. [[Первичный-ритм]], [[Ритмическая-формула]], [[Ритмический-рисунок]])
- **«Одна [из четырёх ритмических структур] находится в поле качеств и работает в событийной сетке. Назовём это ритмической схемой, которая образа не имеет»** — в отличие от ритмического рисунка, «проявленного в большей степени в пространстве»
- **«Формула… на её основе строятся ритмические схемы»** — схема рождается из формулы (см. [[Ритмическая-формула]])
- **Замок для ключа:** «есть замок, и он находится там, где ритмическая схема, то есть в той самой сетке, которую называют сверхсознанием» — чтобы материализовать прописанное в стихотворении, нужно «отследить оба ритма: ритм стиха и ритм события… увидеть точку их совмещения» (см. [[Пророк]], [[Сверхсознание]], [[Стих]])
- **Связь с творящим словом:** «слово творящее… используется в комбинации с ритмической схемой событийной сетки. Для этого слова… завязываются на определённый ритм. Этот ритм в поэзии называется рифмой» (см. [[слово]])
- **Схема как условие проявления звука:** «одной из основных задач, проявляющих работу событийной сетки, является создание условия проявления звука. Звук же является условием проявления образа в пространственной сетке» (см. [[Событийная-матрица]], [[Пространственная-решётка]])
- **Отсутствие образа = работа «на уровне качеств»:** схема не имеет образного обличья, поэтому не распознаётся сенсорами тела — распознаётся только ритмический рисунок, её следствие (см. [[Качество]])
- Объявлена одной из четырёх регулируемых центральным ритмом структур наряду с центром импульсов, схемой Кона и двумя сетками (см. [[Центральный-ритм]])

## Contradictions / Uncertainty
- **«Ритмические структуры — их четыре», а названы две** (схема и рисунок) — две оставшиеся не идентифицированы (Status: лакуна)
- **Схема Кона как «ритма-формула» (79) и «ритмическая схема» (79) — два разных термина в одной лекции:** формула = схема Кона, схема = структура в событийной сетке; лестница «формула → схема» и утверждение «схема Кона есть ритма-формула» увязаны только текстуально (Status: требует формулировки)
- Соотношение с [[Схема-события]] и [[Схема-Кона]] не показано
- Термин «сеть/сетка, которую называют сверхсознанием» сведён с [[Событийная-матрица|событийной матрицей]] по семинарам 53/63–64, но прямого тождества в 79-м не высказано
