# Время

## Summary
«Вре-мя» = «в повторе меня» — время через меру. У времени четыре элемента: (1) процесс естественного (первичного) движения, (2) субстанция-электричество, (3) волновые процессы, (4) мера 62/38. Время сознания — фрагментация волновых процессов; время сверхсознания — реальный процесс в событийной сетке.

## Current Understanding
- Время = «в повторе меня»: через меру (золотое сечение 62/38); «в» + «ре» (повтор) + «мя» (меня); обратное чтение даёт «мер»
- **У времени четыре элемента:** (1) процесс «естественное/первичное движение» (см. [[Естественное-движение]]); (2) субстанция = электричество — среда, где всё прописано (см. [[Электричество]]); (3) волновые процессы в основе восприятия; (4) мера 62/38 = системная закономерность (золотое сечение в растении, теле, изломе камня)
- Время (якут. кэм) = понимание глубоких процессов природы и места в них; мера (кэмэй) = системная закономерность, которую нельзя проигнорировать
- **Время сознания = фрагментация** сознанием непрерывных волновых процессов (привязка к движению планет, стрелок, электронов); без неё сознание «тронулось бы»; прошлое/настоящее/будущее = оценка движения по сетке (назад было, вперёд будет, то, что переносит = настоящее)
- Событийная сетка = Сверхсознание; формируется до появления жизни; работа в сетке — только по предназначению и уровню развития
- Естественное движение — первичная волна, задающая тактовую частоту; базируется на «электричестве» (носитель всего, где сигнал движется с прописанной скоростью)
- Волна порождает модуляции по кольцам, создающие для сознания иллюзию начала/конца событий (псевдоциклы)
- Мир проходит версии (сейчас ~60-я); будущее новой версии = «стоп-кадр» застывших качеств
- Время сознания — иллюзия; время сверхсознания — реальный процесс; у сверхсознания своя единица «фра»
- **Субъективное течение времени = кольца:** чем ниже кольцо, тем чаще циклы; стресс/изменёнка = переход в другое кольцо (пуля летит медленно)
- **Время формируется в лептонном поле (семинар 53):** лептонное поле = среда обитания событийной сетки ([[Сверхсознание]]), где формируется время (см. [[Лептонное-поле]])
- **Время = настоящее время:** время строится из компонентов — схемы Кона, событийная сетка, лептонные поля, сознание человека
- Питание событий = из лептонного поля; ССР сверхрациональна — ничего «на халяву»
- Путешествия в прошлое/будущее — перемещение проекции без искажений траектории, часто без физического тела; мир «полуживой», вытаскивается потенциал → выкидывает обратно (см. [[Кротовая-нора]])
