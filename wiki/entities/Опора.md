# Опора

## Summary
Продолжение тела жреца. Ретранслирует его работу через симпатические связи. Для обычного человека — то же, что для жреца волхв.

## Current Understanding
- Опора = продолжение тела жреца (глазки, уши, руки)
- Ретранслирует обряд жреца на расстоянии через симпатические связи
- Формирует в сознании людей желания, намерения, стремления в определённом радиусе
- Преобразовывает вибрации (глушит для доступности нижним уровням)
- Обратная связь: опора отображает здоровье и проблемы → жрец читает
- Если жрец не заботится об опоре — опора может пострадать физически
- В семье опора = ребёнок
- Из 20 опор реальным может быть только один
- Жреческие опорники = верхушка преподавателей (отображение четвёрки преподаватель/учитель/воспитатель/наставник)
