# Левиты

## Summary
Служители, с которыми, по версии курса, был заключён договор захватчиком для внедрения управления. Часть правоверов, осознанно перешедших на сторону захватчика и уведших население (семинар 32).

## Current Understanding
- Левиты — каста священнослужителей, с которой захватчик заключил договор (семинар 32)
- **Левиты = часть правоверов, осознанно перешедших на сторону захватчика (семинар 32):** уведя население и построив механизм контроля сознания через религии
- Договор с левитами — один из способов захвата наряду с навязыванием богов, избранностью (фашизмом) и модификацией генетики (последняя провалилась)
- Через религиозные институции вводится логика, согласующаяся с интересами захватчика (прославление богов, судьба, избранность)
- В связке с [[Жреческая-иерархия|иерархией]]: религиозные структуры работают на жильцов, удерживая их в зонах доверия
- **Левиты (славянская генетика) — служат носителям программы (семинар 13):** левиты со славянской генетикой, служат носителям программы избранности
