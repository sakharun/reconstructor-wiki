## Core Claims

1. **Звук — транспорт для света Ра** к полной материализации; звук — часть системного процесса, не обособлен
2. **Вибрация порождает волну; волна — платформа для информационных потоков**; волна ничего не переносит сама, но даёт возможность движения тому, что записано в информационных процессах
3. **Дух** — структура, работающая с тёмной материей; формирует вибрационные ниши, запуская волны; дух = процессы до восприятия уха
4. **Душа** — «для ушей» (Д-УШ); мир звука для ушей; появляется на уровне, где формируется звук для слышимости
5. **Иерархия звука:** музыка (16-й уровень, сама для себя) → стих (16→1, управленческий инструмент) → слово (с 12-го уровня, тайное) → речь (дуальность слова) → проза (исполнение/реализация, образная) → разговорная речь (намерение через образ)
6. **Музыка** — изменение характеристик волн и вибраций; первопричина кристаллизации информации; мир сотворён из маленького стихотворения
7. **Стих** — управленческий инструмент; рифма = отображение волновых процессов; «стих = я даю команду»; пишется в изменённом состоянии сознания; тонкие тела чувствуют искажения
8. **Слово** — пакет информационных процессов в стабильной звуковой оболочке; слово = тайное; в букве от 12 до 72 звуков
9. **Проза** — «я выполняю команду»; образная; с прозы начинается чаромутие и подмена слов
10. **Пророк** — не предсказатель, а формирователь событий; создаёт искусственные вибрационные ниши с событийными структурами для коррекции траектории цивилизации; приходит при опасности серьёзного отклонения; существует с обеих сторон (первая и вторая воля); пророк = «скорая помощь»; одиночка (целостен в специализации)
11. **Поэты и музыканты** — посредники между пророком и миром; фрагментируют музыку пророка; удерживают работоспособность вибрационных ниш; их произведения сохраняются на 100–тысячи лет
12. **Демиурги** — системный элемент-детектор; распаковывают «стихи» в реальность; создают миры как проектанты; аналогия: детектор в радиоприёмнике
13. **Кристаллизация информации** — процесс перехода информации в материю через волны и вибрации; обратный процесс = освобождение из материи → бесконечная трансформация
14. **Явное↔тайное** — механизм материализации: явное (дух, открытое) → тайное (слово, запертое) → тайное снова → явное (реализация); циклический спектр
15. **Суть создаёт волну** как импульс; волна постоянна (траектория); качество (наполнение) может меняться; внутренние изменения = информационные пакеты на волнах → формирование внешнего мира
16. **Аналогия радиопередатчика:** генератор = дух (формирователь ниши); передатчик = волны; детектор = Демиург; приёмник = мир для ушей (душа)
17. **Соратник** — совместно+РА+ник (усиливать); только для участников процессов, связанных с РА и траекторией цивилизации
18. **Единомышленник** = одинаковая логика/поляризация; **единомысленник** = единая мысль (уровень волховского круга)
19. **Тело звука** — тонкое тело, отвечающее за восприятие первичной музыки; работает с сознанием только при определённом уровне развития
20. **Телепатия не отменяет звук**: у телепатических цивилизаций звуковое сопровождение мощнее в несколько раз
21. **Спектр** нового: «что-то новое пришло — готовьтесь, будет прохождение спектра; в спектр входит всё: и нравится, и не нравится»
22. **Стихи управленцев** не искажаются (тонкие тела чувствуют лишнее); проза через сознание = подвержена чаромутию
23. **Фантасты** пишут прозой — и у них всё сбывается; их произведения = следствие процессов третичной информационной среды
24. **Искусственный отказ от спектра** (слушать «только классику») вреден; спектр должен расширяться с уровнем развития

## Key Evidence / Details

- Личный опыт лектора: слышание спектрального звука капли воды в изменённом состоянии; слышание 5–7 разговоров одновременно (как Юлий Цезарь)
- Олег Захаров — соратник-хранитель, работает со звуком (музыка); инвалид первой группы, диктует ноты для 19-й книги
- Практическая проверка: здание транслирует волновые процессы на определённое расстояние (проверено в Волгограде, ошибка ~0,5 м)
- Кровь считывает информацию в радиусе ~40 м вокруг человека
- Стихи пишутся через личность как приёмник: ум сравнивает слова из базы, подбирает подходящее; сознание有时 пытается дописать — это чувствуется как лишнее
