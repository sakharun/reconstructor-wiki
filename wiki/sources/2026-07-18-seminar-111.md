## Core Claims

1. **Информация как процесс** — информация — это не данные и не следствие, а сам процесс проявления. Формулировки единой нет; каждая раскрывает своё.
2. **Два типа описания** — статическое (результат, картинка, геометрия, физика, химия) и динамическое (процесс, движение, алгоритм, формула).
3. **Информация бывает прошлая и будущая** — прошлое = происшедшее, будущее = запланированное. Настоящее невозможно описать.
4. **Иное vs Другое** — иное = непознанное, неизвестное; другое = известное, противоположное. Человечество подменяет «другое» на «иное».
5. **Безобразная информация** — без образов, без эмоций. Описывает систему саморегуляции (алгоритм). Образы не нужны для понимания.
6. **Системное зрение** — видеть работу системы через алгоритм, не через образы. Отдельный канал восприятия.
7. **Три типа информации** — первичная (иная форма, целостная), управляющая (структурная, системная), реализующая (образная, фрагментарная).
8. **Мировосприятие, мироощущение, миропонимание, мировоззрение** — четыре уровня взаимодействия с миром; мировоззрение = осознанное совмещение с большой нейросетью.
9. **Лучевая vs Сферическая логика** — узкая (одномерная) vs объёмная (все измерения).
10. **Нейросеть** — каждое качество имеет свою нейросеть. Иерархия: человек → органы → клетки → планета.
11. **Пространство** — часть проявления спектра. Задача: пропустить через спектр и дать право на фрактализацию. Твердь — место экспериментов.
12. **Библиотека качеств** — поле с равномерно расположенными качествами. Модуляция интенсивности = Создатель, Порядок, Космос.
13. **Азбука** — начало реализующей информации. Преддверие формирования пространственных структур.
14. **Цель vs Задача** — цель = образ (конечный продукт); задача = безобразная (характеристики). Сначала задача, потом цель.
15. **Проекция сути** — может быть на человеке и животном одновременно. Дата рождения фиксируется в инфополе.

## Key Evidence / Details

- Информация = процесс, а не следствие. Разрушение пространства обнажает первичную информацию → она уходит в Антимир.
- Мировосприятие = принятие мира в предназначении (ось). Мироощущение = поэты, художники, экстрасенсы. Миропонимание = личность, которая понимает. Мировоззрение = осознанное совмещение с большой нейросетью.
- Лучевая логика = один луч, одно направление. Сферическая = объёмная, все измерения.
- Нейросеть планеты включает нейросети людей. Стихийные бедствия = планетарная реакция через нейросеть.
- Управляющая информация описывает целостность для своего кольца. Реализующая = образная, фрагментальная, работает в пространстве.
- Пространство = твердь, где можно породить новое. Геометрия существует только в пространстве → мироздание и геометрия в одном месте.
- Без образов, эмоций, ощущений = основа познания. Образы = подмена знания, уводят от алгоритма.
- Алгоритм системы саморегуляции: библиотека качеств → модуляция интенсивности → Создатель, Порядок, Космос → иерархия нейросетей.
