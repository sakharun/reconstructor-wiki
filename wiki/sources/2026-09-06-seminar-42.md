## Core Claims

1. **Закон по сути = «За, Кон»** — Кон = схема Системы саморегуляции, породившей мир; всё, что выпадает из целого (кона) — фрагмент; закон — это фрагмент, ограниченный по своей природе
2. **Закон работает только со следствиями** — следствие = поделённое на фрагменты целое, дошедшее до материализации; мысль (безобразное целое) при движении к материализации фрагментизируется (смысл → идея → материальные детали); закон описывает/предписывает точечное приложение внимания к процессу следствия
3. **Закон = технологическая карта** — пример трактора: задача-мысль → смысл (чертежи) → идея (дизайн) → реализация (детали по цехам); каждая деталь рождается в рамках закона и не понимает, зачем создана; её свобода = «доехать до склада по предназначению»
4. **Цивилизация = трактор, страны = агрегаты/органы** — у каждой страны свои законы (технологические карты), их нельзя унифицировать; закон = карта постройки органа; насаждение единых законов = попытка превратить организм в один орган (орган для трансплантации / «пожрать»)
5. **Настоящий закон = только Конституция** — подзаконные акты (включая законы Думы) = отображения/проекции законов для колец ниже; закон живёт весь срок действия технологической карты формирования конкретного сообщества
6. **Закон существует только на стадии формирования цивилизации** — пока растут органы в утробе; когда организм готов, приходит «сборщик» (знает, как устроено целое) и связывает органы через дачу информации о действии всего организма
7. **Зов и отклик:** те, кто пишут законы/конституцию, создают ЗОВ; отклик формирует население — реакция сознания на рамки/ограничения (принять правила игры или уехать)
8. **Осознанный отклик + выборы:** право голоса только у обученных; обучение бесплатно с 16 лет; экзамен в 25; дебаты «Зов ↔ отклик» = обратная связь; допуск к голосованию ещё через 5 лет; модернизированное копное право с участием женщин
9. **«Я винтик» — заблуждение:** каждый человек — носитель качества; его реакция учитывается системой и регистрируется в [[Сверхсознание]]; даже молчаливая осознанная реакция важна
10. **Духовность (впадение в крайность) = путёвка в противоположность:** соприкоснувшись с высшим, надо «хвататься за низшие»; любая крайность системы = крайность → корректирующее событие; полноценная спектральная жизнь идёт одновременно
11. **Очевидность и перепроверка информации:** любая информация — не первоисточник; ищите первоисточник или косвенные следы; без проверки не делайте выводов, ведущих к действию; «кто первый сказал — тот доминирует»
12. **Русский язык = канал, по которому приходит РА** — должен быть в каждой стране как один из языков коррекции (не доминирующий); без него орган живёт своей жизнью (доминирование, отбор потенциала, опухоли)
13. **У России не будет друзей, только взаимовыгодные партнёры** — нельзя дружить, можно иметь взаимовыгодные отношения на определённое время; даже славяне (Беларусь, Украина) = отдельные органы с разными предназначениями
14. **Мужское/женское начала:** низшее женское = «хавайся в жито» (нравственность, «сегодня хочу — завтра нет»); низшее мужское = чистый эгоист; высшая точка мужского = взаимовыгодный обмен
15. **Однополярный vs многополярный мир:** США = однополярный (единые законы для всех = один орган); Путин = многополярный (природное состояние нормального развития любой системы)
16. **Экономические законы должны быть индивидуальны для каждой сферы** (металл = стабильная система, хлеб = лотерея); единые экономические законы = одна техкарта для стекла/металла/резины → нездоровая конкуренция, трансатлантические корпорации
17. **Коронавирус (2020) как знак:** пандемия на уровне цивилизации = прибытие изменений (орган=лёгкие → дыхание → горение); отмена/перенос референдума; изменения прибыли, потому что система застряла в ограничении (излишняя стабильность)

## Key Evidence / Details

- **Свобода фрагмента:** «у вас свобода до склада доехать» — свобода = совмещение с траекторией (см. [[Траектория]], [[Предназначение]])
- **Доброкачественная опухоль:** орган без приёмника коррекций собирает много потенциала, не использует (складированный материал) → преобразование в злокачественную → корректирующие события для организма
- **Технологическая карта предписывает не только материал, но и квалификацию токаря:** если народ не соответствует уровню закона (траектории) — деталь забракована по качеству (ситуация с текущей Конституцией: страну приближают к траектории, но народ не готов)
- **Европа как пример:** миграция = смена токаря по металлу на токаря по дереву в процессе исполнения запчастей (совершенно разные знания/результат)
- **Конституцию должны писать профессионалы уровня верховного жреца / отображающие его** — с такой логикой, чтобы её нельзя было трактовать двояко; иначе любую конституцию перевернут, трактуя её «на законном основании»
- **Полиция/силовые структуры:** должны ежегодно сдавать экзамены на знание структуры управления; сейчас эгоистов больше (статистика); видение перспективы — сменятся с изменением Конституции
- **Стихотворение Вадима** о «передаёт бразды правления тем, кто может послужить» — уходящие в забвение
- Финансирование «Дождя» Газпромом = «событие вне логики»; олигархи «нос по ветру держат» и поляризуются в сторону России (ощущение силы/потенциала)
- Осторожная реакция на вторичные темы: о Путине — «не универсальный солдат», выполняет свою траекторию; защищает не Путина, а логику
