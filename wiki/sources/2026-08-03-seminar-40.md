# Занятие 40 — Внутренний мир

## Core Claims

1. **Наш мир — орган/механизм Вселенной** со схемой «[[Система-саморегуляции]]» для реализации своих процессов относительно целого
2. **Внутренний мир ≠ виртуальный мир** — внутренний мир ≠ то, что внутри тела; это выход сознания на вселенские процессы, с которыми соприкасаются тонкие тела в силу траектории; поэтому внутренний мир **безграничен**. Внешний мир = зона реализации сознанием импульсов/мотивации внутреннего мира по уровню развития; **ограничен**.
3. **Человек не сосуд**, но содержит структуры временно в состоянии сосуда (сознание личности + генетика/тело); «сосуд» = стереотип мужского начала
4. **Гармония** = перетекание интенсивности внимания между внутренним и внешним миром по золотому сечению (62/38). Иная/вторая воля пытается вытеснить сознание во внешний мир → сознание подконтрольно до 97%; нарушение гармонии = человек становится «балластом» → корректирующие события; при ~80% подконтрольности цивилизации — корректирующие события по цивилизации (пандемии, затем катастрофы)
5. **Катастрофа** = постановка перед выбором: меняться или усугубляться; выход — через переосмысление и первые закономерности (изменил внутри → меняется снаружи) → возврат к траектории/предназначению; сход с траектории = «шёл не туда» (пропадают деньги, связи, здоровье)
6. **Иерархия управления:** сознанием управляет сверхсознание через подсознание; надсознание управляет сознанием тоже через подсознание; **всё идёт через подсознание** (конечный инструмент); подсознание не управляет сознанием, но выполняет заложенные программы
7. **Внимание = кабель коммутации** — через него сознание подключается к точке, куда направил импульс; время и пространство для внимания не важны; через внимание можно помочь/навредить/программировать/забирать или давать потенциал; вспоминание = подключение к информационной матрице; практика дробления внимания
8. **Закладка программы в подсознание:** поставить просто, снять сложно; примеры — «уши горят», «чихание», «знак кошек»; реакции (уши горят, поворот головы на взгляд) = уже программирование подсознания
9. **Интуиция = работа подсознания** (предупреждение о процессах, которые могут повредить); передаётся по наследству (прописана в генетике); при отсутствии — можно создать
10. **Распаковка генетики рода** при определённом уровне стресса; осознанное проведение действий в этот момент = наработанное личное качество; иначе — просто «не помнит, что делал»
11. **Тонкие тела** построены на вибрации центральных ниш (мысль, смысл, идея, реализация); завязаны симпатическими связями с вселенскими процессами; сознание соприкасается с ними через чакры
12. **Чакры = устройства ввода-вывода информационных потоков** (не «энергетические» центры), через которые сознание соприкасается с тонкими телами; чакры объёмные, не в плоскости; связаны с полевыми структурами; надсознание и сверхсознание работают с 3 верхними чакрами, сознание и подсознание — с 3 нижними, сердце — середина целого, завязано на все
13. **Сердце = середина целого**; связь со всеми структурами через ассоциативное чувство; сердцем только чувствуют; чувство ≠ интуиция (у сердца есть мера, у подсознания меры нет)
14. **Сознание находится вне тела** (над ним); тело = силовая структура; мозг = устройство ввода-вывода; серебряная нить = кабель между телом и тонкими телами, обрезание = смерть; первичные импульсы формируются в тонком плане; среди тонких тел — особняк: духовность/душа (первое тонкое тело перед физическим собирает импульсы)
15. **У тела есть своё сознание**, управляющее процессами организма; сознание (личность) диктует телу движение через это
16. **Изменённое состояние сознания** — через подсознание (скорости другие) и через сверхсознание (скорости огромны: вопрос = ответ одновременно, логическая цепочка теряется); гипноз — средство перевода сознания; любой фрагмент сознание обязано описать → названия (медитация, нирвана, изменённое состояние) = попытки описать соприкосновение сознания с потоками
17. **Псевдо-целостность / псевдо-нирвана:** сознание создано работать с фрагментами, целостность никогда не увидит в чистом виде; нирвана = естественное прохождение всех этапов на практике, но это псевдосостояние
18. **Ясновидение/яснознание/ясноведание:** ясновидение = сознание+подсознание (с образами); яснознание и ясноведание — без образов, чисто информационные процессы (уровень понимания); подсознание даёт картинку под уровень развития сознания (техника безопасности); образы = фрагментированное восприятие, чем ниже сознание — тем больше просит образов; экстрасенсы работают только в сознании/подсознании, в сверх/надсознании их нет
19. **Подсознание/ведогон:** сознание — зона резонирования, подсознание — ограничение (тот, кто материализует); сознание личное, у него аналог подсознания — ведогон (всё зашито на родовом/планетарном уровне); в общее поле подсознания выходят с уровня волхвов; «подсознание знает всё» — только о процессах, идущих на материализацию
20. **Компьютерная аналогия:** человек = компьютер в сети; экран = внешний мир, сеть/интернет = внутренний мир; если сознание не перебрасывает внимание в «сеть» — не участвует в глобальных процессах, сеть «перестаёт воспринимать»
21. **Эгоизм = решение своих проблем за счёт чужого потенциала**; противопоставление нравственности (заработал сам, потратил на себя = низшее проявление индивидуальности, не эгоизм); одинаков везде, но мужское начало в эгоизме получает удовольствие, женскому — неприятно
22. **Благополучие** = «благо получать»; благо = богу ладное = то, что по траектории; потребительство ≠ благополучие (подмена понятий); страны на материальных благах → высокая суицидность
23. **Вторая воля равнозначна нашим задачам**; будет противником, пока не заставим её качество работать на себя; борьба идёт за каждую единицу как носителя генома/набора качеств; «я винтик» — глубокое заблуждение; принцип целостности мира и равнозначимости каждого элемента
24. **Внутренний мир = возможность быть и слыть, значит, мыслить**; когда вытягивают из внутреннего мира — вытягивают из структуры (становитесь ходячим телом, легко контролируемым)
25. **Принципы системы: отражение, отображение, проекция, источник** (реальный); человек-носитель постоянно отражает, отображает, проецирует
26. **Низшие проявления начал:** женское низшее = нравственность (при росте → возможность + начинает соблюдать правила); мужское низшее = подчинение правилам/порядкам (при росте → «избранный», игнорирует законы)
27. **Практика = якорь/база:** любая информация без практики — полуфабрикат (можно вытеснить, исказить, поломать); проведённое через практику знание прописывается в генетике, передаётся по наследству, является опорой
28. **Перевод предметов/событий в систему** (к стихиям: ограничение, резонирование, индивидуальность, изменения) — практика-подготовка к теме определения предназначения

## Key Evidence / Details

- Личный эксперимент лектора: тема определения предназначения «отработана на живых носителях, работает»
- Личный опыт программирования подсознания: «шесть чихов», «знак кошек» (в Череповце), «рука чешется» — примеры закладки и сложности снятия программ
- Пример матери исключительно с ребёнком = раздвоение внимания (один канал сканирует, второй — в обычной жизни)
- Компьютерная программа-аналогия: наблюдение загрузки процессора (как «подсмотреть», как мир использует человека)
- Заблуждение «подсознание знает всё»: подсознание знает процессы, идущие на материализацию, не более
- Пример схода с траектории: пропажа денег → связей → здоровья; неудачник = «отлучили от кухни»; удачник = «у того, кто даёт»; «дача» от слова «давать»
