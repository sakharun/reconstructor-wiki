## Core Claims

### Камень как информационное хранилище
- Камень = хранилище генетической информации планеты, зашитой в момент формирования
- **Этимология:** «Ка» (хаа) — вместилище души; «Мень» — то, что меняет → камень меняет файлы генетики
- Камень излучает информацию при деформации через **пьезоэлектричество**
- В камне зашита информация о том, «как должно выглядеть» всё живое на планете (эксперимент с лягушкой и пермалоем)

### Пространственная решётка (Илим)
- На определённом уровне голографической матрицы формируется решётка из **шестигранников**
- Чем меньше шестигранники — тем плотнее вещество
- В кристаллах решётки зарождается **первичное электричество**
- Камень формирует импульс, распространяющий информацию о том, «что должно существовать и в каком виде»

### Работа жрецов с камнями
- Жрец — «примитивный программист» системы; работает через речь и обряды
- Речь жреца — программирование третичной среды (формирование вторичных признаков первичных процессов)
- Без жреческой речи обряды не работают
- Жрец **перепрошивает** камни: стирает природную информацию и записывает новую
- Два типа камней: «намоленные» (годы работы) и прошитые за месяц-полтора

### Храмы и пассивные излучатели
- Храмы строятся на местах, где уже стояли_PROGRAMMING_ камни жрецов
- Православные храмы либо подпёрты старыми камнями, либо содержат их
- Механизм: толпа нагружает фундамент → разгрузка → камни излучают информацию
- Церковь **утеряла** методики программирования камней; использует старые прошивки
- Некоторые храмы перепрограммированы некачественно → людям «тянет на старославянские праздники» при хождении в церковь

### Дольмены
- **Этимология:** «долю менять» (доля = судьба)
- Расположены на планетарных информационных зонах
- Использовались для **обнуления генетических наработок** (излечение через сброс качеств)
- Волновод: отверстие = волновод, литые стенки с определённой геометрией
- Геометрия дольмена определяет характер воздействия

### Генетика и род
- Каждый человек носит информацию **всего своего рода** за все поколения
- Распаковка генетики происходит на **4-м уровне стресса**
- Распаковываются только **необходимые для траектории** качества
- При самоубийстве человек попадает в «ад» — сжатое проживание недоработанных качеств

### Места силы
- **Природные:** планетарные информационные потоки (Земля общается «с коллегами по цеху»)
  - Сильноточные: ничего не ставят (человек может не вернуться)
  - Слаботочные: иногда строили храмы; женщин не пускали к алтарю (техника безопасности)
- **Искусственные:** жрец ставит камни → место силы
- **Жрец = место силы** (а не камень); камень — инструмент
- Волхву камень не нужен (он совмещает приёмник и передатчик РА)

### Мужское и женское начала (углубление)
- Женщина — **руководитель** (внутренние процессы семьи)
- Мужчина — **управленец** (внешние процессы)
- Женские тонкие тела работают с внутренними планетарными процессами
- Мужские тонкие тела — с внешними

### Четыре постулата (повтор)
- **Дуальность** → **Спектр** → **Мера** → **Фрактал**
- Всё упирается в эти четыре элемента; они проявляются в:
  - Ограничениях (самоограничение/законы)
  - Резонировании (обман/взаимовыгодный обмен)
  - Индивидуальности (возможности/нравственность)
  - Изменениях (разрушение/исследование)
- Мир = **четверичная информационная проекция** (4 зоны: третичная → жрецы/волхвы; четверичная → наш мир)

### Наука и целостность
- Наука — фрагментарна по природе (.zone резонирования)
- Диссертации строятся на фрагментах; целостность уничтожит систему доказательств
- Философия описывала целое, но была нецелостной; **веды** были наиболее целостными
- Веды **закрыты** по важным причинам; раскроются после определённых событий

## Key Evidence / Details

- Эксперимент с лягушкой в пермалоевой оболочке → мутация, отсутствие потомства
- Сергий Радонежский расплавил снег вокруг стоп → пример реальной работы (не «чудо»)
- Самоубийца в буферной зоне проживает недоработанное в сжатом виде (реальный «ад»)
- Личный опыт лектора: 6 лет спрессованного прохождения качеств при работе с ведущим
- Память Ленина = «мавзолей как излучатель генетики» (перепрошит камни вокруг)
- Кремация = большой выброс информации на большую площадь (имела смысл для воинов в войне)
