## Core Claims

1. **Вера — внутренний мотиватор**. «Я верую» = осознанное намерение по траектории: «Я такой-то, находясь в трезвой рассудке, намереваюсь сделать действие в определённом событии, согласно знания о принадлежности события к траектории».
2. **Доверие ≠ Вера**. Доверие — мотиватор с внешним источником (информация для логики сознания). Сознание доверяет логике. Вера — внутренний процесс; «вы не можете верить в Христа, вы только доверяете информации об Христе. Чтобы верить — станьте Христом».
3. **Надежда — два вида**. Надежда на внешний мир = иллюзия (ищете, на кого переложить). Надежда на себя = доверие к себе через знания.
4. **Проблема — информационная среда для отработки качества**. Проблема = событие, в которое вы входите для отработки качества согласно траектории. Система сама подтягивает людей для решения; не пропускайте связи.
5. **Терпение — маркер свой/чужой по траектории**. Если терпите — нарушаете меру. Терпение = кричащий знак. «Я это терпеть не буду» и уход = карма с усугублением. Терпение показывает, что есть проблема и она решаема.
6. **Любовь — внутреннее движение по обмену качествами**. «Принять человека как он есть» = заблуждение; это терпение на время. Любовь = работа по обмену качествами в семье.
7. **Воля — ловит малое Я**. Когда волен = РА без препятствий проходит через внутренний мир. Свобода = иллюзия сознания, уводит от траектории.
8. **Религия — начальная школа**. Молодые сознания приходят для наработки Доверия (тестовый режим). Не хорошо и не плохо.
9. **Цивилизация — подготовка к переходу**. Сейчас идут те, кто достиг высшего уровня + огромная карма. Задача — подготовить людей, чтобы цивилизация не пошла на 61 версию.
10. **Успех — у-дача**. Природа ничего не даёт просто. Удача = боеприпасы для выполнения предназначения. Если сразу всё хорошо — не совсем хорошо.
11. **Индивидуальность — каждый кирпичик уникален**. Если одинаковые — здание не простоит. Использование индивидуальности = стабильность цивилизации.
12. **Четыре элемента в логике**: Любовь (запуск импульса) → Вера (движение РА) → Надежда (опора на себя) → Терпение (маркер траектории).

## Key Evidence / Details

- «Я верую» = осознанное намерение по траектории на основе знаний о Коне.
- Доверие — инструмент сознания; слабая точка сознания = доверие; манипуляторы используют это.
- Надежда на внешний мир = поиск, на кого переложить проблему; на себя = доверие через знания.
- Проблема = информационная среда; система подтягивает людей для решения; не пропускайте связи.
- Терпение = маркер: терпите → нарушаете меру; корректирующее событие неизбежно.
- Любовь ≠ «принять как есть»; это терпение на время. Любовь = обмен качествами.
- Воля = ловит малое Я; когда волен = РА без препятствий. Свобода = иллюзия.
- Религия = начальная школа; молодые сознания; тестовый режим для Доверия.
- Цивилизация = подготовка к переходу на следующее кольцо; 61 версия — повтор.
- Успех = у-дача; боеприпасы для предназначения.
