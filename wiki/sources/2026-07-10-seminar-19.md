## Core Claims

1. **Эгрегор** — системная программа (не существо), работающая по схеме. Название = "Объединитель". Работает в паре с сознанием (противоположность).
2. **Два источника:** 1) Природа — целостная, лежит на поверхности; 2) Наше мнение — фрагментарное, построенное на логике сознания.
3. **Дух** рождает вибрационные ниши перед рождением мира. Каждый объект имеет свою вибрационную нишу.
4. **Теург** — единственный, кто вмещает целостную задачу цивилизации. Первичная мысль проходит через Теурга.
5. **Боги** = "быть о ги" (движении) — вторичный волховской круг, транслируют импульс от Теурга.
6. **Волхвы** = "ловить то, что спрятано". Ловят истину, целостность. Второй круг, физическая оболочка.
7. **Жрецы** = "жизнь рекущие". Работают через сознание (внешний путь). Пирамида начинается с верховного жреца.
8. **Разум (Сверхсознание)** — сеть, где все соединены. Сверхсознание = быстрая обработка информации. Все "марионетки" в сверхсознании.
9. **Надсознание** — содержит схему Кона. Сопрягает различные миры и меры.
10. **Эгрегор = посредник** между внутренним миром (разумом) и исполнителем (человеком). Эгрегор внутри человека, во внешнем мире его нет.
11. **Функции эгрегора:** а) Объединение людей для задачи; б) Распределение потенциала (связи, деньги, здоровье).
12. **Сход с траектории** = попадание под другой эгрегор, который начинает снимать потенциал.
13. **Конфликт** — обязательное начало совмещения. Совмещение = стирание границ между представителями эгрегора.
14. **Мостики** — результат совмещения; убирают конфликтность, создают договорённости.
15. **Прямое видение** — реальное видение через физические органы (не ясновидение). Ясновидящий = работа с подсознанием.
16. **Гипноз** — насилие над структурами плотного и тонкого плана.
17. **Вторая воля** — транслирует через механические приспособления (психогенератор). Не работает с эгрегорами.
18. **Президент (Путин)** — отображает работу волхва (работает в кольце цивилизации). Жрецы работают за свой род.
19. **Рождение ребёнка** — родовая траектория, не личная.
20. **Эмоции** — знаковое проявление залипания.

## Key Evidence / Details

- Схема: Мысль → Теург → Волхвы → Эгрегоры → Сверхсознание (разум) → Надсознание (схема Кона) → Жрецы → Люди
- Эгрегор не может ни увеличится, ни усохнуть; может изменить интенсивность работы
- Каждый эгрегор содержит фрагмент центральной задачи цивилизации
- Эгрегоры бывают: личные, родовые, общественные, межмировые
- Гармоничный мир = мир, где все качества наработаны и применяются в мере → переходит в следующее вибрационное кольцо
