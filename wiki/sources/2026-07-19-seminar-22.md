## Core Claims

1. **Троица + четвёртый элемент** — Любовь = Изменения, Надежда = Резонирование, Вера = Возможности, **Терпение = Ограничение**. Надежду надо убить первой — она мешает быстрым решениям.
2. **Любовь = изменения, за счёт которых существует стабильность** — пока есть внутреннее движение, есть оболочка (Хаа). Прекратилось движение → оболочка распадается.
3. **Подсознание = автопилот** — управляет нами, когда мы идём по городу. Сознание доверяет подсознанию больше, чем первичному импульсу.
4. **Мысль ≠ Подсознание** — мысль приходит редко, связана с тем, чего никогда не было; подсознание посылает грубые, яркие импульсы с образами.
5. **Мотивация** — задание вектора движения; мысль более глобальна.
6. **Внутренний дребезг** — вибрации состояния, чёткое воспоминание; работа подсознания.
7. **Луч внимания** — физическая составляющая; упирается в тонкие тела человека; можно помочь или уничтожить.
8. **Бог (Айыы)** — источник, излучающий Посыл (первопричина, истина) из Солнца (Күн).
9. **Теург** — вмещает целостную задачу, запускает первичное движение.
10. **Боги (Айыылар)** — быть о движении; начало материализации.
11. **Волхвы** = давят на педаль газа; **Жрецы** = поддерживают холостой ход обрядами.
12. **Истина** — источник иного; сознание всегда стремится к истине (системное проявление).
13. **Нирвана** — состояние во всех четырёх траекториях (личная, родовая, общественная, мировая); микро-нирвана = ясность в определённом кольце.
14. **Любовь и стабильность** — оболочка существует, пока есть внутреннее движение; физическое тело, информационная оболочка, семья, бизнес, Родина.
15. **Влечение** — внутреннее (из траектории) и внешнее (формирует сознание). Эгрегор подаёт импульс.
16. **Россия = Ра сеять** — источник изменения в цивилизации; без изменений распадётся.
17. **Любовь = тяжёлая работа** — внутренние процессы согласно предназначению; во всём системное проявление.
18. **Теория струн** — 4 концепции: калибровочная симметрия, суперсимметрия, гравитация как вибрация, дуальность.

## Key Evidence / Details

- Подсознание управляет, когда мы идём по городу — автопилот для пьяного.
- Мысль приходит редко и связана с тем, чего у вас никогда не было — подсознанию не с чем сравнить.
- Луч внимания — серьёзная вещь; им можно управлять и воздействовать на человека.
- Верховные жрецы реагируют на мысль как на вибрацию — указание к действию.
- Надежду надо убить первой — мешает быстрым и правильным решениям.
- Любовь = те изменения, за счёт которых существует стабильность.
- Влечение = вовлечение; внешнее формирует сознание, внутреннее формирует траекторию.
- Россия = Ра сеять; без внутренних изменений распадётся.
- Семья = заведомо процесс внутреннего совмещения; без конфликтов существовать не может.
- Нирвана = ни рвано = целостное; микро-состояния нирваны в обычной жизни.
