## Core Claims
- Событие = совмещённое совместное бытие; качество, встроенное в череду взаимоотношений
- Событие нельзя сформировать — оно уже сформировано
- События = цикличные матрицы, замкнутые на себя
- Микрособытия = мелкие события, склеенные вниманием
- Внимание = клей, склеивающий микрособытия
- Интенсивность = приоритетность микрособытия; переключение интенсивности = управление
- Иерархия событий: микрособытия → основные → жизнеорганизующие → жизнеутверждающие
- Самоидентификация = запуск сознания → формирование личности
- Ведогон = личное подсознание; общее поле подсознания = память всех миров
- Открытие звёздной памяти = доступ ко всем реинкарнациям
- Первичные приоритеты: питание, размножение, сохранность рода, самореализация
- Управление через смену приоритетов = замена важных на неважные
- Системная музыка = музыка, воздействующая на информационную среду
- Многоуровневое стихотворение = стих, раскрывающийся на разных уровнях
- Мантры = звуки, откликающие тонкие тела; требуют действий и движений
