## Core Claims

1. **Честь** = «ЧЕ СОТВОРИВШИ НЕСТИ». Целостное восприятие. Зона исследования. Природная адекватность (не поляризована религией/партией). Высшее проявление = волхвы. Целомудрие = мудрое от целого; благородство = благое для рода.
2. **Правда** = правило, подтверждающее право на доминирование через логику сознания. Правда у каждого своя (это верно). Правила сознания = «это работает так» = статус после совмещения. «Я думаю» = сознание выдаёт варианты, личность сравнивает. Личность = производная сознания. Правда = призма сознания; маркер для ССР.
3. **Совесть** = весть, прошедшая совмещение; внешняя общественная программа. Основа сообщества. Традиция = «твердь Ра в движение через Ци». Обычай ≠ традиция. Праздники с обрядом = традиция, без обряда = обычай.
4. **Стыд** = генетическая память предков; душа = драйвер совмещения всех со всеми. Стыд даёт возможности через адекватность взаимодействия. Контролирует процессы, порождаемые совестью. Без стыда → общество вразнос (геноцид). Стыд = планетарная вещь. Навязанный стыд = стыд паразитирующей цивилизации.
5. **Иерархия:** ЧЕСТЬ → СОВЕСТЬ → СТЫД → ПРАВДА. Честь формирует импульсы → совесть; стыд контролирует совесть; правда = маркер для ССР.
6. **Весть** = информация, имеющая отношение к первоисточнику; передаётся теми, кто принял в состоянии «вера». Несёт структуру, правила, задачу сообщества и опорные элементы внутренней/внешней культуры.
7. **Спектральное понимание проблемы** — проводите через зоны: исследование → ограничение → резонирование → возможности. Проигнорировали зону → проявится с минусом.
8. **Отсутствие качества** = брешь (как уязвимость для вирусов); через брешь можно войти и управлять.
9. **Сообщество** начинается с подавления индивидуальности до уровня диалога. Без подавления = нет диалога; с чрезмерным подавлением = корректирующие события.
10. **Природная адекватность** — действия, сопряжённые с основами ССР; не обвиняет, не выделяет; видит процессы относительно схем.
