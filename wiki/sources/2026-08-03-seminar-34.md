## Core Claims
- **Доверие = внешний комфорт + внутреннее напряжение** (противоположность веры: внешнее напряжение + внутренний комфорт)
- Доверие — функция сознания, физиологического уровня; вера — отношение к целостному, через тонкие тела
- **Противоположность ССР — сам человек** (иллюзия, что ССР ограничивает; на деле пока она есть — живёшь)
- **Нирвана = псевдоцелостное состояние** — сознание прикоснулось ко всем тонким телам, но никогда не увидит настоящую целостность (не для этого создано); яркое присутствие смысла + внутренний комфорт
- **Четыре зоны формирования доверия:** резонирование, ограничение, индивидуальное проявление (чудо), изменение (исследование/разрушение)
- **Доверие через резонирование** — на удобной логике; «всё сошлось» = замыкание круга; не проверяется; основа религий и манипуляций
- **Доверие через ограничение** — череда ограничений с яркими образами → самоограничение; снимается обучением; разрушается через удаление опорной базы (атака на историю)
- **Доверие через индивидуальность (чудо)** — проявление вопреки логике; страх сознания потерять опорную базу блокирует принятие; расширение «флешки» через удивление → исследование → знание
- **Доверие через изменение** — исследование = изнутри, разрушение = снаружи; факт разрушения вызывает доверие к разрушителю; опасный вариант — под факт подводят логику (оболочки вокруг Христа)
- **Практика = единственный иммунитет:** логика, проведённая через практику, даёт 100% доверия и стоит на страже информационных атак
- Два проявления сознания: **широкое** (работает на первичный источник, входит в неудобные процессы) и **узкопрофильное** (считает себя вершиной пирамиды, ищет виноватых)
- Мудрость = «растить думу»: сказать → сделать → показать; мудрый никогда не идёт на слепое доверие
- Доверие = «кочка на болоте» или временная опора сознания для выстраивания логики
- Подсознание всегда участвует в реализации того, чему вызвано доверие

## Key Evidence / Details
- Пример манипуляции: молодой человек без айфона → Навальный «Путин виноват» → замыкание круга → доверие → действия
- Пример ограничения: электрощит → образы взрыва/пожара/вдовы → обучение снимает блокировку
- Атака на историю СССР: удаление базы → из фрагментов выстраивается логика сдачи (ЕГЭ убирает объёмное понимание)
- Гомосексуализм: естественный (закрытие родовой ветки) vs искусственный (80%, создан для контроля роста)
- Нирвана для волхва ≠ нирвана для обычного человека; разница в объёмах сопряжения информации
- Четыре траектории: личная → родовая → общественная → мировая; через них тонкие тела соприкасаются со Вселенной
- Научное познание = теория струн и т.п.: чудо перестаёт быть чудом, пока кто-то не задаст новый вопрос
