## Core Claims

1. **Событие невозможно формировать** — оно формируется Духом через вибрационные ниши; матрица событийности появляется при создании вибрационных ниш. Сознание — исполнитель, а не создатель.
2. **Ключ к событию** — внутреннее состояние (карма + траектория); вы притягиваетесь по противоположности (нет качества) и отторгаетесь по приобретению (качество наработано).
3. **Событие не имеет образов** — образы начинаются, где есть пространство и время. Событие поляризовано качеством, но образа не имеет.
4. **Событийная матрица (сетка)** — как нейронная сеть головного мозга; события = точки соединены связями разных цветов и вибраций; видит внутренние процессы и истинные мотивации.
5. **Фрагменты события** — событие делится на фрагменты для осознания; начало-конец = отдых для сознания; без фрагментации → депрессия (даже в позитивном событии).
6. **Системное забвение (небытие)** — состояние между событиями; отсутствие Ра/траектории; депрессия, отсутствие смысла жизни; падшие хранители попадают туда.
7. **Ясновидящие → ясноведающие** — видящие (3 варианта) → ясновидящие (6) → ясно знающие (28, потолок) → ясноведающие (волхвы, могут менять связи).
8. **Кольца событий** — чем больше кольцо, тем дольше по времени; семья = минуты, цивилизация = миллионы лет.
9. **Конфликт = непринятие** — полное непринятие чего-либо; 4 стадии; «спуск на тормозах» = карма с усугублением.
10. **Ускорение прохождения** — можно пройти 3-4 фрагмента за один; нужно тянуть человека рядом.
11. **Спектр события** — микро-качества = модуляции; вверх по кольцам, в ширь по модификации; пример с гвоздём.
12. **Событие постоянно в работе** — не прекращает движение; кто-то входит, выходит, кого-то выплёвывают.

## Key Evidence / Details

- Событие = мясорубка, которая постоянно вращается; что туда попало — оттуда вылезает определённый состав.
- Ключ = карма + траектория; карма = повтор, траектория = новое.
- Сетка = нейронная сеть; видит внутренние процессы, истинные мотивации; ясноведающие могут менять связи.
- Фрагменты = начало-конец = отдых для сознания; без фрагментации → депрессия.
- Системное забвение = отсутствие Ра; падшие хранители попадают туда за применение не по траектории.
- Конфликт = полное непринятие; 4 стадии; «спуск на тормозах» = карма.
- Ускорение: тянуть человека рядом; если он не тянет — система подставит другого.
- Событие не имеет начала и конца (для сознания имеет); цикл.
