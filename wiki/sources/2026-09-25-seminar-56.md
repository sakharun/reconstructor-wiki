## Core Claims

### Два уровня описания
- Любой процесс описывается **снизу** (с позиции фрагментарного) и **сверху** (с позиции целостного); время сознания = описание снизу, семинар описывает время **сверху**
- Без знаний о [[Система-саморегуляции|КОНе]] размышлять о времени бесполезно; нужно ~70% лекций из свободного доступа

### Этимология «время»
- **«Вре-мя»** = «в повторе меня»: «в» (приставка) + «ре» (повтор) + «мя» (меня); обратное чтение даёт корень «мер»/«мера»
- Время = действие в повторе «меня» через меру (золотое сечение 62/38)
- Время (якут. **кэм**) — понимание глубоких процессов природы и своего места в них; мера (якут. **кэмэй**) — системная закономерность, которую нельзя проигнорировать

### Событийные кольца и поле
- **Событие** = количество качеств, связанных переходами и введённых в состояние цикла
- **Событийное кольцо** — цикл качеств БЕЗ образов (на работе «кольцо» носит образы: переоделся → инструктаж → наряд → детали); источник новых оттенков качества для носителя
- **Носитель качества = суть**: суть из библиотеки не участвует напрямую, создаёт проекции; личность = проекция сути
- Втягивание в кольцо — по **предрасположенности**: отсутствие оттенка своего основного качества, нужного для предназначения; **случайностей нет** (случайность = удел низкого уровня сознания)
- В кольце находишься, пока система не добьётся нужных качеств; «хочухи» личности не в счёт — корректирующие события всё равно вернут на траекторию
- **Повторы прохождения кольца = судьба/карма**; момент первого входа = **сутьба** (суть бытия); судьба от «суд бытия» = осуждён на время в одном месте (тюрьма), но это восприятие сознания
- «Мир станет тюрьмой» — уровень, после проживания которого возможен выход; единственная свобода воли = выполнить предназначение
- **Событийные кольца образуют событийное поле**, связи между кольцами пробрасываются с учётом задачи мировой траектории
- **Событийная матрица формируется ДО появления жизни**; потом создаются разумные существа

### Событийная сетка = сверхсознание
- Сетка = подобие нейронной сети мозга; ядра нейронов = **точки возможных вариаций прохода сознания**
- Выходов из кольца много (~20), личность видит 1–3; чем выше развитие, тем больше вариантов видишь и осознанно выбираешь
- Работа в сетке — по предназначению + уровень развития; ведущий допущен как наблюдатель («держи свечку»); «человек разумный» присвоено без намёка на разум
- **Разум = соприкосновение со сверхсознанием** (событийной сеткой)
- В кольцах есть **проекционная студия**: образ = самый низ, поле подсознания; ясновидящие видят судьбу в образах = видят **предрасположенность** к варианту выхода, не неизбежность

### Две сетки
- **Пространственная сетка** — формирует пространство (= следствие); фильм в ВК описывает только её
- **Событийная сетка** — источник; работают очень немногие, на публику не выходят

### Лептонное поле
- Сетка находится в **лептонном поле**; «лептонное» = «лепят тон» (тон звуковой)
- В поле существует тон в определённых кольцах — место называется **вибрационная оболочка**; работа Духа по формированию вибрационных оболочек = работа в лептонном поле

### Вечность и бесконечность
- **Вечность** = «ве» (внутреннее движение) + «че» (че/чи/ци = целое) + «ность» (нести) = внутреннее движение целого нести
- **Целое** = самодостаточная система одновременного саморождения и саморазрушения с постоянным саморазвитием; жители не видят заложенной задачи (поляризатора) = наш Кон
- КОН делает всё руками/головами/тонкими телами жителей; КОН = целостное, наполняющие = фрагменты
- **Бесконечность** = саморождение через саморазрушение; Вселенная бесконечно расширяется И бесконечно сворачивается; объём один и тот же, обусловлен размерами лептонного поля; жители видят только расширение (сознание фрагментарно, видит начало-конец)

### Версии и первичная волна
- Перед миром ставится задача (лектор: **«центр реализации»**, к чему относится — не распаковано)
- Под задачу из событий вяжется сеть; строится на всё время существования голографической матрицы → **сверхстабильна**; возможны сверхминимальные коррекции (пример: человек жил полгода без объяснений медицины)
- Работа с неведомым/иным → **многократные повторы с коррекциями = циклы = версии** (сейчас 60-я)
- Каждая новая версия: небольшие изменения в пересечениях качеств и связях → в **образах** большие подвижки (архитектура, религии, наука) = цивилизации-останки; **отношения не меняются** — сетка с качествами та же, образы меняются
- **Прошлое/настоящее/будущее** = оценка сознанием движения по сетке: назад было, вперёд будет, то, что переносит тебя = настоящее
- В сетке до старта прописаны все варианты исходов (**каркас**) — для познания неведомого, не запрет на новое; в системе есть **изъян** (системный элемент) — иначе схема Кона не соответствовала бы смыслу
- Система заинтересована: неведомое, пройдя схему, приобретает прогнозируемый результат = уровень программиста событийного поля вырос

### Путешествия в прошлое/будущее, мерности, кротовые норы
- Перемещение проекции без искажений траектории = путешествие в прошлое/будущее
- В альтернативный выход (из ~20, не выбранный) + потом в свой = **новая мерность**
- В чужое кольцо (где не должен был находиться) = **новое измерение**
- Телепортация = на небольшое время и с отклонением от русла = отклонение от траектории
- **Кротовая нора** = искусственные переходы между событиями; скорость естественного движения пойдёт относительно перехода → **наслоение событий**; путешествия всегда кратковременные, иначе «психушка»
- **Наслоение событий**: ушёл от событий → времени мало, событий много → «рвать начинает» → берёшь самые важные, остальные уходят в карму с усугублением → «крыша едет»
- Путешествия во времени реальны, чаще **без физического тела**; там мир «полуживой»; вытягиваешь за собой потенциал → выкинет обратно

### Генетики и искусственный сверхчеловек
- Земные генетики собирают «конструктор идеального человека»; но путь наработки качеств снизу игнорировать нельзя — придётся проходить в более короткий срок с **отягощениями по интенсивности**; самые тяжёлые моменты — адаптация к социуму («будет война»)
- **Будут две войны:** с искусственным интеллектом (ИИ строится на трёх законах робототехники — «начали с ограничений → закончат в проявлении без таковых»)
- Нужно строить не **интеллект** (маленькая часть сознания), а **искусственное сознание**; если построят искусственное сознание — система примет его как игрока с правами развития и размножения (станет естественным)
- Фантасты не придумывают: «сознание не способно придумать того, чего в мире уже не было»; мы — мир теней, проецируем то, что было или спускают

### Изменёнка = другое кольцо
- **Естественное движение** = скорость, с которой сознание строит вокруг себя кольцо из логики описания целостности мира; скорость разная по кольцам
- **Изменёнка = вынужденное или осознанное перемещение в другое кольцо** для сознания
- Естественное движение («есть» = естественное) — структура среди первичных регуляторов (схем Кона), запускающая движение

### Универсальная субстанция — электричество / Перун
- **Субстанция на виду и невидимая** = то, что наполняет собой всё и создаёт первичное движение; движение = следствие процессов в ней
- Это **электричество** (не розеточное); в древности описано как бог **Перун** (Сүҥ Дьааһын / Сүгэ Тойон); Перун = первый
- **Пространственная сетка полностью работает на электричестве**; электричество работает во всём, наука применяет, но не понимает природу
- Тело человека работает на электричестве полностью; органы — по дневному/ночному циклам; **камень** имеет два источника выработки электричества: природный (сжатие-разжатие холод/тепло) и удары жрецов (радиация информации на большое расстояние → в кровь → съём и передача информации)
- **Храмы** строятся на камнях; деревянные храмы работают только на каменном основании; христиане признают, что строили церкви на старых славянских местах обрядов
- **Первичная волна ≠ электрический импульс:** первичная волна = информационная волна; электричество = поле, в котором волна проходит
- **Электричество ≠ энергия:** электричество = среда, в которой всё происходит/прописывается/живёт; потенциал = то, что прописано в электричестве; сигнал в том электричестве движется с прописанной скоростью (может быстрее света в 200 млн раз, может медленнее звука)
- **Тесла** чуть-чуть соприкасался с настоящим электричеством

### Волновые процессы и кольца матрицы
- Волновые процессы разнятся по кольцам: **в первом кольце волна одна** (первичная) — проходит матрицу один раз, задаёт опорную скорость = естественное движение; это движение целого
- Кольцо ниже: волна с подъёмами-спадами (модуляции); ещё ниже — мельтешение = начало/конец событий для сознания
- Сознание в псевдоциклах находит начало и конец; гребень прошёл → «событие закончилось», а это спад интенсивности между волнами одного события; человек не совмещает волны → «по жизни не везёт», идут усугубления (структура та же, интенсивность растёт)
- Первичная волна = **закладка, первый опор движения, потенциалов в событиях**; = генератор с несущей частотой и тактовым генератором-опорником; вся первичная волна несёт весь потенциал

### Провал в начале процесса
- Первичная волна: **гладь → провал → всплеск → движение**; любой нормальный процесс по траектории начинается с **провала** (бизнес кормишь, женитьба «с провала» — другое событие, чем ухаживание); если сразу подъём — к неуклонному спуску
- Время в кольце выдерживают ~2 года — потом идут наверх

### Свобода, случайность, уровень развития
- Первичная фрагментация → иллюзия свободы; максимум свободы + рядом всегда слово «случайность» = **дно модуляции**
- Чем выше развитие → меньше свободы/случайности, больше ответственности за выбор («сверхответственность», «не спишешь на стрелочника»)
- 95% людей не склонны к внутренним изменениям; ясновидящий-новичок «мнит себя великим», когда всё сбывается; высший уровень ясновидения = **яснознание**: радуются, когда предсказание НЕ сбылось (человек изменился), но теряют в деньгах

### Информационная плотность
- Мир = информация; пространство = информация определённой плотности; **информационная плотность = введение новых параметров** (вес, плотность, вибрации соответствия плотному); бесплотные существа отличаются отсутствием этих параметров
- Наличие/отсутствие параметров завязано на траекторию и 4 траектории/предназначение

### Завершение версии, бессмертие, время
- Когда **первая волна первого кольца** доходит до конца матрицы (несёт эталон) — работа версии заканчивается, всё начинается сначала; периодически подгружается новая задача на следующие 100 циклов/версий
- Существа = отображение/проекции → **фактически бессмертны**; уничтожить качество нельзя — это повлияло бы на многие процессы
- Волна порождает первичные процессы = **время сознания** (прошлое/настоящее/будущее); есть **четвёртый элемент** — оболочечная структура внутри трёх
- «Не рождается всё, а **оживает всё**»; естественное движение = первичное движение, движение = жизнь
- Время = процессы, проявленные через слово теми, кто знал о них
- **Итог: у времени не три, а четыре элемента:** (1) процесс «естественное движение»/«первичное движение»; (2) субстанция = электричество (не изучено); (3) волновые процессы в основе восприятия; (4) мера 62/38 как системная закономерность (золотое сечение — везде: растения, тело, камень ломается по ЗС)

### Время сознания и стоп-кадр
- **Время сознания** = фрагментация сознанием непрерывных волновых процессов; цепляем к движению планет/стрелок/электронов; необходимость: без фрагментации сознание тронулось бы
- **Стоп-кадр качества:** когда волна прошла по матрице, события застывают на позиции интенсивности качеств → эти застывшие качества = **будущие версии**; мы сами, как несменяемые участники, строим своё будущее на тысячи реинкарнаций
- Настоящее время = суть проявления: ты в повторе существуешь как проекция сути; закончится отработка качества — появится другое

### Ответы на вопросы
- **Искажение истории** = проявление спектра: событие фиксируется → идёт путь искажений → исказится до неузнаваемости → пойдёт назад к первоисточнику; отсюда борьба историков и псевдоисториков
- **Скорость течения времени** = кольца: чем ниже кольцо, тем чаще циклы; переход между кольцами меняет течение времени; субъективное ощущение = нахождение в разных кольцах; стресс/изменёнка (пуля летит медленно) = переход в другое кольцо
- **Параллельные миры** — не раскрыто
- **Восприятие в изменёнке** = попадание в другую тактовую частоту; картинка мира меняется за **фра** — единицу времени ведущего (соотносится с десятками часов)
