## Core Claims

1. **Сознание** — механизм с чёткими системными схемами. Устройство для совмещения новых знаний. Стремится к стабильности, но постоянно в нестабильности из-за новых знаний.
2. **Два вида сознаний:** динамическое (система толкает через траекторию) и статическое (сам осознанно набирает знания).
3. **Два метода восприятия информации:**
   - **Прямое** — датчики (глаза, уши) сняли → сравнение с базой → точное совпадение
   - **Ассоциативное** — что-то похоже → продолжение мышления (без точного совпадения)
4. **Кольца вибрационные** — уровни роста осознания. Ассоциация через кольца не прыгает. Вышестоящее существо должно обратить внимание, чтобы низшее развивалось.
5. **Сознание не видит целостность** — работает только с фрагментами. Целостность только через изменённое состояние.
6. **Искусственные ложные ассоциации** — внедрены в базу для управления:
   - **Свастика** — символ описания строения мира; специально выбита ассоциацией с Гитлером
   - **Христианский крест** — фрактал свастики (одна ветка, тень)
   - **"Два высших образования"** — ассоциация грамотности (не всегда оправдана)
   - **"Народ избранный"** — ассоциация привилегий
7. **Свастика** — относится к категории "мысль" (первичная задача). Если выбита — замещается суррогатом.
8. **Механизм загрузки информации:** память → сравнение → внутреннее доверие → схема загрузки (без проверки). Информация → практика = знание.
9. **Информация поступает из 4 источников:** подсознание, сверхсознание, надсознание, внешний мир.
10. **Четыре типа действий:**
    - Мотивированное сознанием (изнутри)
    - Демонстрируемое сознанию (показывают)
    - С обратной связью (делаешь сам)
    - Без обратной связи (наблюдаешь)
11. **Мораль** = мор + ал (высшее проявление → умирание). Морально устойчивый = ?
12. **Авторитет** — сознание подчиняется успешному человеку. Но его рекомендации со своей траектории, к вашей не относятся.
13. **Мячик с верёвочкой** — образ человека на траектории: отлетает от гвоздика (предназначения), но не дальше периметра.
14. **Механизм сект:** новая информация → имя Бога → действие → позитивная ассоциация → сравнение с cũми религиями → принятие.
15. **Манипуляция** — управление сознанием. Не хорошо и не плохо. Учитель манипулирует учеником.
16. **Творец** — в начале разрушитель (вторгается со новым), потом созидатель (когда стабилизируется).
17. **Структурное мышление** — без ассоциаций, без образов, без эмоций. Только в изменённом состоянии.
18. **Сознание не проверяет информацию** — проверить можете только вы сами.
19. **Диванные войска** — показали ролик → человек спорит, как будто был там лично.

## Key Evidence / Details

- Сознание работает даже во сне (сны = проекции виртуального мира)
- "Промысел божий" = христианское описание системы саморегуляции
- Революция = склупы и славы (дуальность)
- Подсознание = общая память; доступа нет обычному человеку (даже жрецы не входят)
- "Хочешь познать мир в целостном проявлении? Ничего не сравнивай" — источник Вадима
