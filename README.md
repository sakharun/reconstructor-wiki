# Словарь «Реконструктор Сознания»

Статический сайт-словарь по вики из папки `wiki`: 773 концепции и 38 сущностей с определениями,
связями, источниками и открытыми вопросами.

## Быстрый старт

```bash
npm install
npm run dev      # соберёт контент и запустит Vite
npm run build    # контент + проверка типов + сборка в dist/
npm run preview  # локальный просмотр собранной версии
```

Контент пересобирается командой `npm run content` — она читает `wiki/**/*.md` и складывает JSON в
`public/content/`. Эта папка в `.gitignore`: в репозитории хранятся только исходные Markdown-файлы.

## Что внутри

```
wiki/                 исходная вики (не изменяется)
scripts/              конвейер контента
  build-content.mjs   Markdown → JSON, ссылки, обратные ссылки, поиск, граф
  lib/markdown.mjs    рендер, вики-ссылки, оглавление
  lib/slugs.mjs       транслитерация и нормализация имён
shared/stemmer.js     русский стеммер для поиска (общий для сборки и клиента)
src/                  React-приложение
  pages/              Главная, Указатель, Статья, Граф, О проекте
  components/         палитра поиска, статья, боковая панель, мини-граф
  lib/                загрузка контента, MiniSearch, тема
public/404.html       генерируется после сборки (fallback для GitHub Pages)
```

## Как устроен конвейер

1. Статья разбирается на `# Заголовок`, `## Summary` (определение) и остальные разделы.
2. Английские служебные заголовки (`Current Understanding`, `Evidence`, …) переводятся для
   отображения; исходные файлы не меняются.
3. `[[Цель|алиас]]` превращается в ссылку. Разрешение идёт по имени файла, заголовку и, как
   запасной вариант, по основе слова — поэтому `[[Антимире]]` ведёт на «Антимир».
4. Ссылки на источники и служебные страницы остаются неактивными чипами с подсказкой.
5. Считаются обратные ссылки, степень узлов, индекс MiniSearch (быстрый и полный) и граф.

## Деплой

Сайт полностью статический. Готовый workflow — `.github/workflows/deploy.yml`: при пуше в `main`
(включая изменения в `wiki/`) сайт пересобирается и публикуется на GitHub Pages.

- Для репозитория проекта (`username.github.io/repo`) базовый путь задаётся автоматически:
  `VITE_BASE=/repo/`.
- Для пользовательского сайта (`username.github.io`) уберите `VITE_BASE` из workflow или задайте
  `VITE_BASE=/`.
- Для Netlify/Vercel достаточно команды `npm run build` и каталога `dist`; для SPA добавьте
  редирект `/* /index.html 200`.

## Поиск и горячие клавиши

- `Ctrl+K` / `Cmd+K` или `/` — командная палитра.
- В палитре есть переключатель «по всему тексту»: полный индекс (~2 МБ) загружается по требованию.
- Поиск нормализует `ё → е` и использует русский стеммер: `воля`, `воли`, `волей` находят одну статью.
